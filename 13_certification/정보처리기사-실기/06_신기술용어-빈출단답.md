# 06. 신기술 용어 · 빈출 단답

> 정보처리기사 실기(NCS 2020 개정) 대비. 용어→정의 / 정의→용어 단답 대비용.
> ⭐ = 최빈출. 답안은 표의 "핵심 정의"를 1~2문장으로 그대로 써서 대응.

---

## 1. 데이터 / 빅데이터

| 용어 | 핵심 정의 |
|------|-----------|
| 빅데이터(Big Data) ⭐ | 기존 방식으로 처리하기 어려운 대용량·다양·고속 데이터와 이를 분석·활용하는 기술. **3V = Volume(양)·Velocity(속도)·Variety(다양성)**, 확장 시 **Veracity(정확성)·Value(가치)** 포함 |
| 하둡(Hadoop) ⭐ | 대용량 데이터를 여러 노드에 분산 저장·병렬 처리하는 오픈소스 프레임워크. 핵심은 HDFS(저장) + MapReduce(처리) |
| 맵리듀스(MapReduce) | 대용량 데이터를 Map(분할·처리)과 Reduce(집계·병합) 두 단계로 나눠 분산 병렬 처리하는 프로그래밍 모델 |
| HDFS | 하둡 분산 파일 시스템. 대용량 파일을 블록 단위로 여러 노드에 분산 저장하고 복제하여 장애에 대응 |
| NoSQL ⭐ | 관계형(SQL)의 고정 스키마·조인을 벗어나, 대용량·비정형 데이터를 유연하게 저장·처리하는 비관계형 DB (Key-Value, Document, Column, Graph 등) |
| 데이터 마이닝(Data Mining) ⭐ | 대량의 데이터에서 통계·기계학습 기법으로 숨겨진 패턴·규칙·상관관계를 발견하는 기술 |
| OLAP(Online Analytical Processing) | 데이터 웨어하우스 등의 다차원 데이터를 사용자가 대화식으로 분석하는 기술 (Drill-down/up, Slicing, Dicing, Pivoting) |
| 데이터 웨어하우스(DW) ⭐ | 의사결정 지원을 위해 여러 운영 시스템의 데이터를 주제 지향적으로 통합·축적한 데이터 저장소 |
| 데이터 마트(Data Mart) | 데이터 웨어하우스의 부분집합으로, 특정 부서·주제에 맞게 구성한 소규모 데이터 저장소 |
| 데이터 레이크(Data Lake) | 정형·반정형·비정형 데이터를 가공 없이 원본 형태 그대로 대규모로 저장하는 저장소 |
| 메타데이터(Metadata) | 데이터에 대한 데이터. 데이터의 구조·속성·의미·이력 등을 설명하는 정보 |
| 데이터 마이그레이션(Migration) | 기존 시스템의 데이터를 새로운 시스템·저장소로 추출·변환·적재하여 이전하는 작업 |
| 다크 데이터(Dark Data) | 수집·저장은 되어 있으나 분석·활용되지 않고 방치된 데이터 |
| 하둡 에코시스템 | 하둡을 중심으로 데이터 수집·저장·처리·분석을 지원하는 도구 집합. **Sqoop**(RDB↔하둡 연동), **Tajo**(SQL 기반 분석), **Pig**(스크립트 데이터 처리), **Hive**(SQL식 데이터 웨어하우징) |

## 2. 클라우드 / 인프라

| 용어 | 핵심 정의 |
|------|-----------|
| SaaS(Software as a Service) ⭐ | 소프트웨어(응용)를 클라우드에서 서비스로 제공하여 사용자가 설치 없이 인터넷으로 이용 |
| PaaS(Platform as a Service) ⭐ | 응용 개발·실행에 필요한 플랫폼(OS·런타임·개발환경)을 서비스로 제공 |
| IaaS(Infrastructure as a Service) ⭐ | 서버·스토리지·네트워크 등 IT 인프라를 가상화하여 서비스로 제공 |
| 도커(Docker) ⭐ | 애플리케이션과 실행환경을 컨테이너 단위로 패키징하여 배포·실행하는 오픈소스 컨테이너 플랫폼 |
| 쿠버네티스(Kubernetes) ⭐ | 다수의 컨테이너를 자동 배포·확장·관리(오케스트레이션)하는 오픈소스 플랫폼 |
| 컨테이너 / 가상화 | 컨테이너는 OS 커널을 공유하며 앱을 격리 실행하는 경량 기술, 가상화는 하이퍼바이저로 하나의 물리 자원을 여러 가상 자원으로 나누는 기술 |
| 서버리스(Serverless) | 개발자가 서버 인프라를 관리하지 않고 함수(코드) 단위로 실행하며 사용한 만큼만 과금하는 클라우드 실행 모델 |
| 그리드 컴퓨팅(Grid Computing) | 지리적으로 분산된 다수의 컴퓨팅 자원을 네트워크로 연결해 하나의 고성능 시스템처럼 활용 |
| 클러스터링(Clustering) | 여러 대의 컴퓨터(노드)를 묶어 하나처럼 동작시켜 고가용성·부하분산·성능을 확보 |
| 하이퍼바이저(Hypervisor) | 하나의 물리 서버 위에서 여러 가상머신(VM)을 생성·실행·관리하는 가상화 소프트웨어 |

## 3. 네트워크 신기술 ⭐

| 용어 | 핵심 정의 |
|------|-----------|
| SDN(Software Defined Network) ⭐ | 네트워크의 제어부(Control Plane)와 데이터 전송부(Data Plane)를 분리하여, 소프트웨어로 네트워크를 중앙 집중 제어·관리하는 기술 |
| NFV(Network Function Virtualization) | 라우터·방화벽 등 네트워크 기능을 전용 하드웨어가 아닌 소프트웨어로 가상화하여 범용 서버에서 구현하는 기술 |
| 메시 네트워크(Mesh Network) ⭐ | 각 노드가 다른 여러 노드와 그물망처럼 연결되어, 중앙 장비 없이 노드 간 직접 중계로 데이터를 전달하는 네트워크 |
| 애드혹 네트워크(Ad-hoc) | 고정 인프라(AP·기지국) 없이 이동 단말끼리 자율적으로 구성·연결하는 임시 무선 네트워크 |
| WDM(파장분할다중화) | 하나의 광섬유에 서로 다른 파장(색)의 빛을 여러 개 실어 동시에 전송하는 광 다중화 방식 |
| IoT(사물인터넷) ⭐ | 사물에 센서·통신 기능을 내장하여 인터넷으로 서로 연결·데이터 교환하는 기술 |
| M2M(Machine to Machine) | 사람의 개입 없이 기계(장치) 간 직접 통신하여 정보를 주고받는 기술 (IoT의 기반 개념) |
| 5G | 초고속·초저지연·초연결(대량 접속)을 특징으로 하는 5세대 이동통신 |
| 지그비(Zigbee) | 저전력·저속·근거리 무선통신 표준(IEEE 802.15.4). 홈네트워크·센서망 등에 사용 |
| 블루투스(Bluetooth) | 근거리 무선 개인 통신(WPAN) 기술로 기기 간 저전력 무선 연결을 제공 |
| NFC(Near Field Communication) ⭐ | 약 10cm 이내 초근거리에서 비접촉으로 데이터를 교환하는 무선통신 (결제·태그 등) |
| 비콘(Beacon) | 블루투스 저전력(BLE) 기반으로 주기적 신호를 발신해 근거리 위치·정보를 제공하는 근접 서비스 기술 |
| 로라(LoRa) | 저전력 광역(LPWAN) 통신 기술. 저속이지만 저전력으로 장거리 IoT 통신에 사용 |
| USN / WSN(무선 센서 네트워크) | 다수의 센서 노드를 무선으로 연결하여 환경·사물 정보를 수집·전달하는 네트워크. USN은 언제 어디서나 센서정보를 활용하는 개념 |
| MEC(엣지 컴퓨팅, Edge/Mobile Edge Computing) ⭐ | 데이터를 중앙 클라우드가 아닌 사용자·단말과 가까운 네트워크 가장자리(Edge)에서 처리해 지연을 줄이는 기술 |
| Fon(폰) | 자신의 무선 AP(WiFi)를 개방·공유하는 대신 다른 Fon 회원의 AP를 함께 이용하는 무선 공유 커뮤니티 서비스 |
| 피코넷(Piconet) | 블루투스·UWB 기술을 이용해 여러 기기가 마스터-슬레이브로 구성하는 소규모 임시 무선 네트워크 |
| VPN(Virtual Private Network) ⭐ | 공중망(인터넷) 위에 암호화된 터널을 만들어 사설망처럼 안전하게 통신하는 가상 사설망 |

## 4. AI / 응용

| 용어 | 핵심 정의 |
|------|-----------|
| 머신러닝(Machine Learning) ⭐ | 명시적 프로그래밍 없이 데이터로부터 규칙·패턴을 학습하여 예측·분류하는 인공지능 기술 |
| 딥러닝(Deep Learning) ⭐ | 다층 인공신경망(Deep Neural Network)을 이용해 데이터의 특징을 스스로 학습하는 머신러닝의 한 분야 |
| 텐서플로우(TensorFlow) | 구글이 개발한 오픈소스 머신러닝·딥러닝 프레임워크(라이브러리) |
| 블록체인(Blockchain) ⭐ | 거래 데이터를 블록에 담아 사슬처럼 연결하고, 다수 참여자가 분산 저장·검증하여 위변조를 방지하는 분산 원장 기술 |
| 디지털 트윈(Digital Twin) ⭐ | 현실의 물리적 대상·시스템을 가상 공간에 동일하게 구현하여 시뮬레이션·분석·예측하는 기술 |
| 메타버스(Metaverse) | 현실과 가상이 융합된 3차원 가상 세계에서 사회·경제·문화 활동이 이루어지는 공간 |
| RPA(Robotic Process Automation) ⭐ | 사람이 하던 규칙적·반복적 업무를 소프트웨어 로봇(봇)이 자동으로 수행하는 업무 자동화 기술 |
| 챗봇(Chatbot) | 사용자와 자연어로 대화하며 질문에 응답·업무를 처리하는 자동 대화 프로그램 |
| AR / VR / MR | AR(증강현실): 현실 위에 가상 정보 중첩 / VR(가상현실): 완전한 가상 환경 몰입 / MR(혼합현실): 현실과 가상을 결합·상호작용 |
| 양자 컴퓨팅(Quantum Computing) | 큐비트(Qubit)의 중첩·얽힘을 이용해 여러 상태를 동시에 계산하는 초고속 병렬 연산 컴퓨팅 |

## 5. SW / 웹 ⭐

| 용어 | 핵심 정의 |
|------|-----------|
| 매시업(Mashup) ⭐ | 서로 다른 웹 서비스·오픈API·콘텐츠를 결합하여 새로운 서비스를 만드는 기술 |
| RIA(Rich Internet Application) | 데스크톱 응용과 같은 풍부한 UI·상호작용을 웹 브라우저에서 제공하는 웹 애플리케이션 |
| 반응형 웹(Responsive Web) ⭐ | 하나의 웹 페이지가 접속 기기(PC·태블릿·모바일)의 화면 크기에 맞춰 레이아웃이 자동 조정되는 웹 |
| 시맨틱 웹(Semantic Web) ⭐ | 웹 정보에 의미(Semantic)를 부여하여 컴퓨터가 이해·처리할 수 있게 하는 지능형 웹 |
| 온톨로지(Ontology) ⭐ | 특정 분야 개념과 개념 간 관계를 컴퓨터가 이해할 수 있도록 정의·표현한 지식 체계 |
| MSA(Microservice Architecture) ⭐ | 하나의 애플리케이션을 독립적으로 배포·확장 가능한 작은 서비스들로 나눠 구성하는 아키텍처 |
| DevOps ⭐ | 개발(Development)과 운영(Operations)을 통합하여 협업·자동화로 빠른 배포·개선을 이루는 문화·방법론 |
| 로우코드 / 노코드 | 최소한의 코드(로우코드) 또는 코드 없이(노코드) 시각적 도구로 애플리케이션을 개발하는 방식 |
| 그레이웨어(Grayware) | 악성코드는 아니지만 사용자에게 불편·피해를 줄 수 있는 소프트웨어 (애드웨어·스파이웨어 등) |
| 웨어러블(Wearable) | 몸에 착용하여 사용하는 컴퓨팅 기기 (스마트워치·안경 등) |
| 증강 가상현실(Augmented Virtuality) | 가상 환경을 기반으로 현실의 정보·객체를 추가·결합하는 기술 (MR의 한 형태) |

## 6. 보안 신기술 ⭐

| 용어 | 핵심 정의 |
|------|-----------|
| 블록체인(Blockchain) ⭐ | (보안 관점) 분산 원장에 거래를 암호화·연결 저장하여 중앙 관리자 없이 위변조를 방지하는 기술 |
| 양자암호(QKD, 양자키분배) ⭐ | 양자역학 원리(측정 시 상태 변화)를 이용해 도청 시 즉시 탐지 가능한 안전한 암호키를 분배하는 기술 |
| 영지식 증명(Zero-Knowledge Proof) | 비밀 정보 자체를 노출하지 않고, 그 정보를 알고 있다는 사실만 상대에게 증명하는 기법 |
| 크립토재킹(Cryptojacking) | 피해자의 컴퓨터 자원을 몰래 이용해 암호화폐를 채굴(마이닝)하는 공격 |
| 폼재킹(Formjacking) | 웹사이트 결제·입력 폼에 악성 스크립트를 삽입해 사용자 카드·개인정보를 탈취하는 공격 |
| 스미싱(Smishing) ⭐ | 문자(SMS)의 악성 링크를 통해 금융정보·개인정보를 탈취하는 공격 (SMS+Phishing) |
| 파밍(Pharming) ⭐ | 사용자를 정상 주소로 접속해도 위조된 가짜 사이트로 유도(DNS 변조 등)하여 정보를 탈취하는 공격 |
| 큐싱(Qshing) | QR코드를 이용해 악성 앱 설치·피싱 사이트 접속을 유도하는 공격 (QR+Phishing) |
| 랜섬웨어(Ransomware) ⭐ | 파일·시스템을 암호화하여 사용할 수 없게 만든 뒤 복구 대가로 금전(몸값)을 요구하는 악성코드 |
| APT / 지능형 지속위협 ⭐ | 특정 대상을 목표로 장기간 은밀하게 다양한 기법을 동원해 지속적으로 침투·공격하는 지능형 지속 위협(Advanced Persistent Threat) |
| 다크웹(Dark Web) | 특수 브라우저(Tor 등)로만 접속 가능하고 익명성이 보장되어 불법 거래에 악용되는 은닉된 인터넷 영역 |
| CERT(침해사고대응팀) | 침해사고를 예방·탐지하고 발생 시 신속히 대응·복구하는 전담 조직 (Computer Emergency Response Team) |

---

## 7. 인증 / 표준 제도

| 용어 | 핵심 정의 |
|------|-----------|
| ISMS-P ⭐ | 정보보호(ISMS)와 개인정보보호(PIMS)를 통합한 국내 정보보호 및 개인정보보호 관리체계 인증 제도 |
| CC(공통평가기준, Common Criteria) | IT 제품·시스템의 보안 기능과 신뢰성을 평가·인증하는 국제 표준(ISO/IEC 15408) |
| PIA(개인정보 영향평가) | 개인정보 처리 시스템 구축·변경 시 개인정보 침해 위험을 사전에 분석·평가하고 개선안을 도출하는 제도 |

## 8. 기타 빈출 용어

| 용어 | 핵심 정의 |
|------|-----------|
| 테더링(Tethering) | 스마트폰의 데이터 연결을 다른 기기와 공유하여 인터넷에 접속하게 하는 기능 |
| 스마트그리드(Smart Grid) | 전력망에 ICT를 결합해 전력 생산·소비 정보를 실시간 양방향 교환하여 에너지 효율을 높이는 지능형 전력망 |
| 트러스트존(TrustZone) | ARM 프로세서에서 하나의 칩을 일반 영역과 보안 영역으로 분리해 민감 데이터를 보호하는 하드웨어 기반 보안 기술 |
| 스택가드(StackGuard) | 스택에 카나리(Canary) 값을 삽입해 변조 여부를 검사함으로써 스택 버퍼 오버플로우 공격을 탐지·방어하는 기술 |
| N-Screen ⭐ | 하나의 콘텐츠를 PC·TV·스마트폰 등 여러(N개) 단말에서 끊김 없이 이어서 이용하는 서비스 |
| 오픈API(Open API) ⭐ | 누구나 사용할 수 있도록 공개된 응용 프로그래밍 인터페이스. 매시업의 기반 |

## 부록 · 헷갈리는 용어 구분 (단답 대비)

| 구분 | 차이 |
|------|------|
| 피싱 vs 스미싱 vs 파밍 | 피싱=이메일/가짜사이트, 스미싱=문자(SMS), 파밍=DNS 변조로 정상주소→가짜사이트 |
| DW vs 데이터 마트 vs 데이터 레이크 | DW=전사 통합·정형 / 마트=부서·주제별 부분집합 / 레이크=원본 그대로(정형+비정형) |
| SDN vs NFV | SDN=제어부와 전송부 분리해 SW 중앙 제어 / NFV=네트워크 기능 자체를 SW로 가상화 |
| IaaS vs PaaS vs SaaS | 인프라 제공 / 개발 플랫폼 제공 / 완성 SW 제공 (관리 책임: IaaS>PaaS>SaaS 순으로 사용자 책임 감소) |
| AR vs VR vs MR | 현실+가상정보 / 완전 가상 몰입 / 현실·가상 결합 상호작용 |
| 컨테이너 vs 가상머신(VM) | 컨테이너=OS 커널 공유(경량, 도커) / VM=하이퍼바이저 위 독립 OS(무겁지만 격리 강함) |
