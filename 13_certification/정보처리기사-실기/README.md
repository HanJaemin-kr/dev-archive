## 빈출 TOP (매회 반복되는 것부터)

1. **디자인 패턴 23종** — 생성5/구조7/행위11 분류 + 각 패턴 용도 (보기 주어짐)
2. **정규화 단계** — 1NF~BCNF 각 단계가 제거하는 종속
3. **응집도·결합도** — 강약 순서 + 종류 정의
4. **OSI 7계층** — 계층별 역할·프로토콜·장비·PDU
5. **암호화 분류** — 대칭 vs 비대칭 vs 해시 (알고리즘 섞지 않기)
6. **보안 공격 유형** — 정의 주고 용어 맞히기 (XSS·CSRF·스니핑·스푸핑·랜섬웨어…)
7. **테스트 커버리지 / 통합 테스트** — 구문→다중조건 순서, 하향식=Stub·상향식=Driver
8. **신기술 용어 단답** — 정의 → 용어 (매회 3~5문제)
9. **HRN·페이지 부재·서브넷팅 계산** — 공식 암기형 계산
10. **SQL** — SELECT/JOIN/GROUP BY·HAVING, DDL/DML/DCL 분류

## 함정 포인트 (뒤바꿔 내는 단골)

- 응집도는 **높을수록**, 결합도는 **낮을수록** 좋다.
- 하향식 통합 = **Stub**, 상향식 통합 = **Driver**.
- 암호화: **공개키**로 암호화 / **개인키**로 서명. 대칭키에 RSA·ECC 섞지 않기.
- ARP = IP→MAC, RARP = MAC→IP.
- 무결성 3종(개체/참조/도메인)과 보안 3요소(기밀성/무결성/가용성) 혼동 주의.
