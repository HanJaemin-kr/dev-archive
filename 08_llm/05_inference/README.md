# Inference & Serving

로컬 LLM 배포, 추론 최적화, 하네스 구현.

## 목차

- 로컬 LLM 서버 (llama.cpp, Ollama, vLLM)
- OpenAI-compatible API
- LLM 하네스 설계 및 구현
- Quantization (GGUF, GPTQ, AWQ)
- KV Cache / Batching 최적화
