# 산업별 대표 결함 & 진단법 (Common Faults & Diagnosis by Industry)

산업마다 주력 설비·운전 환경이 달라 **자주 겪는 결함과 열화 메커니즘**이 다르다. 여기선
산업별로 `대표 설비 → 흔한 결함 → 진단법`을 간단히 정리한다. 결함 주파수·진동 파라미터는
[[vibration]], 공진·위험속도 [[resonance]], 전동기 [[motor]], 센서 선정 [[sensor]],
기법 전체 지도는 [[maintenance-strategy]], 공정 도메인은 `11_process/` 참고.

## 먼저 — 공통 회전기계 결함 (모든 산업 공통)

산업 불문 회전기계에서 가장 흔한 결함들. 상세·계산식은 [[vibration]].

| 결함 | 특징 주파수 | 1차 진단 |
|------|------------|----------|
| 불평형(Unbalance) | 1×RPM | 진동 스펙트럼(1× 방사방향) |
| 정렬 불량(Misalignment) | 2×RPM 우세 + 축방향 | 진동 + 정렬 측정(레이저) |
| 느슨함(Looseness) | 1× 다수 고조파·0.5× | 진동(하모닉 다발) |
| 베어링 결함 | BPFO/BPFI/BSF/FTF | **포락선(Envelope)** + 고주파 |
| 기어 결함 | GMF ± 사이드밴드 | 진동 + 오일 분석 + TSA |
| 공진 | 구조 fₙ 고정 | 범프/런업([[resonance]]) |
| 캐비테이션 | 광대역 고주파 랜덤 | 진동 + 공정(흡입압) |

> [!tip] 원칙
> **진동으로 기계 결함을 특정하고, 다른 기법(오일·열화상·초음파·전류)으로 교차 확인**한다.
> 진동만으로 부족한 곳(윤활·전기·초기)은 상보 기법이 더 빠르다([[maintenance-strategy]]).

## 철강 (Steel)

| 항목 | 내용 |
|------|------|
| 대표 설비 | 압연기(워크롤·백업롤·감속기·유압압하), 연주기(주형 오실레이션·롤), 대형 송풍기/팬, 소결·코크스, 크레인·컨베이어, 순환수 펌프 |
| 자주 겪는 결함 | 감속기 기어 마모·피팅, **저속·대하중 베어링** 손상(수분·스케일), 롤 편심·채터(판 품질 직결), 유압 오염·누설, 팬 부착물 불평형, 고온 열변형 |
| 진단법 | 진동(기어 GMF·사이드밴드), 저속 베어링은 **AE/포락선**(초기), 오일 분석(기어박스·유압), 압연 채터 → 진동+판두께 상관, 열화상(전동기·베어링 과열) |
| 환경 특성 | **고온·분진·수분·충격** → 견고/고온 센서, 냉각·방진, 케이블 보호 |

## 석유화학 / 정유 (Petrochemical / Refinery)

| 항목 | 내용 |
|------|------|
| 대표 설비 | 원심펌프(대량), 압축기(원심·왕복·스크류), 증기터빈, 열교환기, 반응기, 팬/블로워, 교반기 |
| 자주 겪는 결함 | 펌프 **캐비테이션**·씰 누설·건식운전, 압축기 **서징(surge)**·폴링, 왕복동 밸브 누설·피스톤링 마모, 정렬·커플링, 튜브 파울링·부식 |
| 진단법 | 진동 + **공정변수(흡입압·유량·차압)** 병행, 캐비테이션(광대역 고주파·소음), 왕복동 → **PV선도·초음파·크랭크각 동기**, 서징 → 압력맥동+진동, 씰 누설 → 초음파/가스검지 |
| 환경 특성 | **방폭(가연성 가스)** → ATEX 본질안전 센서([[sensor]]), 부식, **연속운전(정지 곤란)** → 온라인 상시감시 |

## 반도체 (Semiconductor)

| 항목 | 내용 |
|------|------|
| 대표 설비 | 진공펌프(드라이·**터보분자펌프 TMP**), 칠러, 컴프레서, FFU(팬필터유닛), 이송로봇·스테이지, MFC, 스크러버 |
| 자주 겪는 결함 | TMP **초고속 로터 불평형**·베어링, 드라이펌프 오염·마모, **미세진동(수율·나노 정렬 직결)**, 칠러 컴프레서 결함, 로봇 반복정밀도 저하 |
| 진단법 | **초정밀 저진폭 진동** → 고감도 500 mV/g([[sensor]] 감도), 진공 성능(도달압·펌핑속도) 트렌드, 초음파(초기 베어링), 파티클 카운트, 방진 설계 관리 |
| 환경 특성 | **초청정·미세진동 관리·초고속** → 저노이즈·고감도, 비접촉 우선 |

## 발전 (Power)

| 항목 | 내용 |
|------|------|
| 대표 설비 | 증기/가스 터빈-발전기(대형, **슬리브/저널 베어링**), 보일러 급수펌프, FDF/IDF 팬, 냉각탑, 변압기 |
| 자주 겪는 결함 | 축 편심·**오일훨(oil whirl)/오일휩(whip)**, **위험속도 통과**, 열적 굽힘(rotor bow), 불평형·정렬, 베어링 바빗 마모, 발전기 전기적 결함 |
| 진단법 | **와전류 변위계**(축 상대진동, API 670)·키페이저([[sensor]]), **궤적(orbit)·축중심선** 분석, 위험속도·캠벨([[resonance]]), 런업/코스트다운, 발전기 → MCSA·부분방전 |
| 환경 특성 | **대형·고속·연속·트립 보호(실시간)** → 상시 보호계측(API 670) |

> [!note] 기타 산업 한 줄 감각
> **시멘트/제지**: 대형 저속 회전체·컨베이어 → 저속 베어링(AE·포락선). **수처리**:
> 수중·입형 펌프 → 캐비테이션·씰. **풍력**: 증속기 기어·메인베어링 → 진동+오일+SCADA.

## 산업별 진단 포인트 요약

| 산업 | 대표 설비 | 지배적 결함 성격 | 1차 진단기법 |
|------|----------|----------------|-------------|
| 철강 | 압연·팬·저속 베어링 | 기어·저속대하중 베어링·채터 | 진동 + **AE/포락선** + 오일 |
| 석유화학 | 펌프·압축기 | 캐비테이션·서징·씰(방폭) | 진동 + **공정변수** + 초음파 |
| 반도체 | 진공펌프·로봇 | 초고속·미세진동 | **고감도 진동** + 초음파 |
| 발전 | 터빈-발전기 | 축 편심·오일훨·위험속도 | **변위계(orbit)** + 캠벨 |

## 참고

- 공통 회전기계 결함(불평형·정렬·베어링·기어)은 어느 산업에나 → 상세 [[vibration]]
- 산업별 차이는 **운전 환경(고온/방폭/청정/고속)** 과 **지배 설비**에서 온다
- 진단은 **진동 주력 + 상보 기법**(오일·열화상·초음파·전류)의 조합 → [[maintenance-strategy]]
