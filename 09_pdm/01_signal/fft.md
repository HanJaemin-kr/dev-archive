# FFT & 주파수 분석

## 개념

시간 영역(Time Domain) 신호를 주파수 영역(Frequency Domain)으로 변환.  
진동의 "어떤 주파수 성분이 얼마나 강한가"를 분석해 결함 원인을 특정.

```
시간 영역: 복잡하게 얽힌 파형
     ↓ FFT
주파수 영역: 각 주파수별 크기(스펙트럼)
```

## 핵심 파라미터

FFT 분석의 모든 설정값은 **fmax(최대 분석 주파수)** 와 **라인 수(Lines / LOR)**
딱 두 개만 정하면 나머지가 전부 따라 나온다. 서로 어떻게 엮이는지가 핵심.

### 파라미터 총정리

| 기호 | 이름 | 공식 · 관계 | 예 A | 예 B |
|------|------|------------|------|------|
| **fmax** | 최대 분석 주파수 | (분석 목표로 직접 설정) | 1,000 Hz | 5,000 Hz |
| **Lines** (LOR) | 라인 수 (분해능 라인) | (400·800·1600·3200… 설정) | 800 | 1,600 |
| **Fs** | 샘플링 주파수 | `Fs = 2.56 × fmax` | 2,560 Hz | 12,800 Hz |
| **N** | 샘플 수 | `N = 2.56 × Lines` (보통 2ⁿ) | 2,048 | 4,096 |
| **Δf** | 라인 간격 (분해능) | `Δf = fmax/Lines = Fs/N = 1/T` | 1.25 Hz | 3.125 Hz |
| **T** | 측정 시간 | `T = N/Fs = 1/Δf = Lines/fmax` | 0.8 s | 0.32 s |
| **Δt** | 샘플링 주기 | `Δt = 1/Fs` | 0.39 ms | 78 µs |

### 관계식 한 장

```
fmax  ──(×2.56)──►  Fs = 2.56 · fmax        (주파수 축 상한 = Fs/2)
Lines ──(×2.56)──►  N  = 2.56 · Lines       (샘플 수, 2의 거듭제곱 권장)

Δt = 1 / Fs                                  (샘플링 주기 = 시간 축 간격)
Δf = Fs/N = fmax/Lines = 1/T                 (라인 간격 = 분해능)
T  = N/Fs = 1/Δf = Lines/fmax                (측정 시간)
Lines = N / 2.56                             (유효 라인 수)
```

> [!info] 왜 2.0이 아니라 2.56인가? — 안티앨리어싱 필터
> 이론상 나이퀴스트는 `Fs = 2·fmax` 면 충분하지만, 실제 **안티앨리어싱 LPF**는
> 이상적인 벽(brick-wall)이 아니라 완만하게 감쇠한다. `fmax ~ Fs/2` 구간을
> **가드밴드**로 버려야 통과대역이 깨끗해진다.
> - 그래서 분석기는 관례적으로 `Fs = 2.56 · fmax` (= 2 × 1.28)를 쓰고,
>   스펙트럼 상위 ~20%를 버려 **유효 라인 = N / 2.56** 만 사용한다.
> - N=2,048 → 800라인 · N=4,096 → 1,600라인 · N=8,192 → 3,200라인

> [!tip] 실무 감각
> - **분해능(Δf)을 좋게** = 라인 수↑ 또는 fmax↓ → **측정 시간 T가 길어진다**
> - **높은 주파수까지** = fmax↑ → Fs↑ → 데이터량·연산량↑
> - `T = Lines / fmax` → 같은 fmax에서 라인만 2배면 측정 시간도 2배

## 샘플링 파라미터가 신호에 미치는 영향

Fs(샘플링 레이트)와 N(샘플 수) 두 값이 **① 시간 영역 파형**과 **② 주파수 스펙트럼**에
각각 어떻게 영향을 주는지가 핵심. 아래 표 한 장으로 먼저 정리.

> [!abstract] 한눈에 보기
> | 파라미터 | 시간 영역 (파형) | 주파수 영역 (스펙트럼) |
> |---|---|---|
> | **Fs** (샘플링 레이트) | 얼마나 **촘촘히** 찍히는가 | 분석 가능한 **최대 주파수 = Fs/2** |
> | **N** (샘플 수) | 얼마나 **오래** 재는가 (T = N/Fs) | 주파수 **분해능 Δf = Fs/N** |

### ① 샘플링 레이트 (Fs)

**주파수 영역** — 스펙트럼에서 표현 가능한 최대 주파수는 **Fs / 2 (나이퀴스트 주파수)**. Fs를 높이면 더 높은 주파수까지 분석 가능.

> [!warning] 앨리어싱 (Aliasing) — 가장 주의할 부작용
> Fs/2를 초과하는 주파수 성분은 사라지지 않고 **낮은 가짜 주파수로 접혀(folding)** 나타난다.
> - 겉보기 주파수: `f_alias = | f_real − k · Fs |`  (k = 접히는 정수배)
> - 예) Fs = 1,000 Hz, 실제 900 Hz → **100 Hz 가짜 피크** (900 = 1000 − 100)
> - 실존하지 않는 피크 → **오진단 위험** (없는 결함을 있다고 판단)
> - **대책**: 관심 주파수의 최소 2배 이상 Fs 확보 + ADC 앞단 **안티앨리어싱 LPF(차단 ≤ Fs/2)** 필수 (소프트웨어 다운샘플링 시에도 디지털 LPF 선행)

### ② 샘플 수 (N) / 측정 시간 (T = N / Fs)

**시간 영역** — Fs 고정 시 N↑ → 측정 시간 T↑. 저주파는 한 주기가 길어, 관측하려면 충분한 T가 필요하다 (예: 1×RPM = 25 Hz는 1주기 0.04초 → 최소 몇 주기 담을 T 필요).

**주파수 영역** — N↑ → **분해능 Δf = Fs/N = 1/T** 이 촘촘해져, 인접 피크(1× 회전 주파수와 근처 사이드밴드)를 분리할 수 있다.

> |---|---|---|

### 트레이드오프 & 설정 가이드

| 목표 | 조정 | 부작용 |
|------|------|--------|
| 더 높은 주파수 분석 | Fs ↑ | 데이터량·저장·연산 부담 증가 |
| 주파수 분해능 향상 | N ↑ (또는 T ↑) | 측정 시간 증가, 과도 상태 평균화 |
| 빠른 응답 / 짧은 측정 | T ↓ | 저주파 분해능 저하, 누설 증가 |
| 앨리어싱 방지 | Fs ↑ + LPF | 하드웨어 비용, 필터 지연 |

> [!tip] 핵심 한 줄
> **Fs = "얼마나 높은 주파수까지" / N(=T) = "얼마나 세밀하게".** 둘은 독립적으로 조절되며, 목적에 맞게 균형을 잡는다.

**실전 설정 순서**

```
1. 관심 최대 주파수 f_max 결정  (예: BPFI·고조파까지 5,000 Hz)
   → Fs ≥ 2.56 × f_max          (분석기 관례: 2.56배로 안티앨리어싱 여유)
     Fs = 2.56 × 5,000 ≈ 12,800 Hz

2. 원하는 분해능 Δf 결정         (예: 사이드밴드 분리 위해 1 Hz)
   → N ≥ Fs / Δf ≈ 12,800       → 2의 거듭제곱 16,384 채택

3. 저속 회전체는 T가 회전 주기의 최소 5~10배 이상 되도록 N 확보
```

> [!example]- 앨리어싱 확인 Python 예제 (클릭해서 펼치기)
> ```python
> import numpy as np
> # compute_fft 는 아래 "Python 구현" 섹션 함수 사용
>
> fs = 1000            # 샘플링 레이트 (나이퀴스트 = 500 Hz)
> t = np.arange(0, 1, 1/fs)
> f_real = 900         # 나이퀴스트(500Hz) 초과 → 앨리어싱 발생
> sig = np.sin(2 * np.pi * f_real * t)
>
> freq, amp = compute_fft(sig, fs)
> peak = freq[np.argmax(amp)]
> print(f"실제 주파수: {f_real} Hz → 스펙트럼 피크: {peak:.0f} Hz")
> # 출력 예: 실제 주파수: 900 Hz → 스펙트럼 피크: 100 Hz  (가짜 피크!)
> ```

## Python 구현

```python
import numpy as np
import matplotlib.pyplot as plt

def compute_fft(signal, fs):
    N = len(signal)
    # FFT 계산
    fft_vals = np.fft.rfft(signal)
    fft_freq = np.fft.rfftfreq(N, d=1/fs)
    
    # 단측 스펙트럼 진폭
    amplitude = np.abs(fft_vals) * 2 / N
    
    return fft_freq, amplitude

# 예시: 50Hz + 120Hz 신호
fs = 10000
t = np.linspace(0, 1, fs)
signal = np.sin(2 * np.pi * 50 * t) + 0.5 * np.sin(2 * np.pi * 120 * t)

freq, amp = compute_fft(signal, fs)

plt.plot(freq, amp)
plt.xlabel("Frequency (Hz)")
plt.ylabel("Amplitude")
plt.xlim(0, 500)
plt.grid(True)
plt.show()
```

## 윈도우 함수 (Windowing)

FFT는 신호가 무한히 반복된다고 가정 → 시작/끝 불연속 → **누설(Leakage)** 발생.  
윈도우 함수로 신호 양 끝을 부드럽게 감쇠시켜 누설 억제.

| 윈도우 | 특징 | 적합한 경우 |
|--------|------|------------|
| **Hanning** | 균형 잡힌 누설 억제 | 일반적인 진동 분석 (가장 많이 사용) |
| **Flat Top** | 진폭 정확도 최고 | 정밀 진폭 측정 |
| **Rectangular** | 윈도우 없음 | 충격 신호, 정수 주기 신호 |
| **Hamming** | Hanning과 유사 | 주파수 분해능 중요 시 |

```python
window = np.hanning(len(signal))
windowed = signal * window
freq, amp = compute_fft(windowed, fs)
```

### 윈도우와 유효 분해능

라인 간격 Δf를 줄여도, 윈도우를 적용하면 각 피크의 **폭(main lobe)이 넓어져**
실제로 구분 가능한 분해능은 Δf보다 나빠진다.

> [!important] 유효 분해능 ≈ Δf × ENBW
> ENBW(Equivalent Noise BandWidth, 등가 잡음 대역폭, 단위: 빈)는 윈도우가 한 라인의
> 에너지를 몇 개 빈만큼 퍼뜨리는지를 나타낸다. 근접 피크 분리 여부는 Δf가 아니라
> 이 **유효 분해능**으로 판단해야 한다.

| 윈도우 | ENBW [빈] | 최악 진폭 오차 | 특징 |
|--------|-----------|---------------|------|
| **Rectangular** | 1.00 | −36% (3.9 dB) | 분해능 최고 · 진폭 최악(누설 큼) |
| **Hanning** | 1.50 | −15% (1.4 dB) | 균형 — 진동 분석 표준 |
| **Hamming** | 1.36 | −18% (1.8 dB) | 분해능 약간 우위 |
| **Flat Top** | 3.77 | <0.01 dB | 진폭 최고 · 분해능 최악 |

- 예) Hanning + Δf = 1 Hz → 유효 분해능 ≈ 1.5 Hz. 24.75 Hz 사이드밴드를 확실히
  분리하려면 간격이 유효 분해능의 2~3배는 되어야 안전.
- **근접 피크 분리가 목적**이면 Δf만 보지 말고 `유효 분해능 = Δf × ENBW`까지 고려해
  라인 수를 더 키운다.
- **진폭 정확도**(절대 진동 레벨 판정)가 목적이면 Flat Top, **주파수 위치·분리**가
  목적이면 Hanning.

## 실무 예시: 설정값 계산 → 수집 → 차트

fmax·라인 수만 정하면 나머지(Fs·N·Δf·T·Δt)가 계산되고, 그 값으로 수집·윈도우·FFT 후
차트에 띄우는 전체 흐름.

```
목표: 모터 1,485 RPM (f_rot = 24.75 Hz)
      1×~수 배 고조파와 근처 성분을 분리해서 보고 싶다

1) fmax 결정      : 고조파 관찰 → 여유 두고 fmax = 400 Hz
2) 분해능 목표    : 근접 성분 분리 → Δf = 0.5 Hz
   (Hanning ENBW 1.5 감안 → 유효 분해능 ≈ 0.75 Hz)
3) 라인 수        : Lines = fmax / Δf = 400 / 0.5 = 800  (표준값)
4) 파생값 자동계산:
      Fs = 2.56 × 400  = 1,024 Hz     (앞단 안티앨리어싱 LPF 차단 ≤ Fs/2 = 512 Hz)
      N  = 2.56 × 800  = 2,048
      Δf = fmax/Lines  = 0.5 Hz
      T  = N / Fs      = 2.0 s
      Δt = 1 / Fs      = 0.98 ms
```

```python
import numpy as np
import matplotlib.pyplot as plt

# --- 1. 설정값: fmax·lines 만 정하면 나머지는 자동 ------------------
fmax  = 400                 # 최대 분석 주파수 [Hz]
lines = 800                 # 라인 수 (LOR)
fs    = 2.56 * fmax         # 샘플링 주파수 = 1024 Hz
N     = int(2.56 * lines)   # 샘플 수      = 2048
df    = fmax / lines        # 라인 간격    = 0.5 Hz
T     = N / fs              # 측정 시간    = 2.0 s
dt    = 1 / fs              # 샘플링 주기  = 0.98 ms
print(f"Fs={fs:.0f}Hz  N={N}  Δf={df:.3f}Hz  T={T:.2f}s  Δt={dt*1e3:.2f}ms  lines={lines}")

# --- 2. 신호 수집 (여기서는 모사; 실제로는 DAQ에서 fs로 N개 취득) ---
t = np.arange(N) * dt                        # 0 ~ T, 총 N 샘플
f_rot = 1485 / 60                            # 24.75 Hz
sig = (1.0 * np.sin(2*np.pi*1*f_rot*t)       # 1×
     + 0.4 * np.sin(2*np.pi*2*f_rot*t)       # 2×
     + 0.2 * np.sin(2*np.pi*3*f_rot*t))      # 3×

# --- 3. 윈도우 + FFT (진폭 보정 포함) ------------------------------
win  = np.hanning(N)
cg   = win.mean()                            # 코히런트 게인(Hanning≈0.5) → 진폭 보정
spec = np.abs(np.fft.rfft(sig * win)) * 2 / (N * cg)   # 단측 진폭 스펙트럼
freq = np.fft.rfftfreq(N, d=dt)              # 0 ~ Fs/2, 간격 = Δf

# --- 4. 차트 (설정값을 제목에 표기, x축 0~fmax) -------------------
plt.figure(figsize=(9, 4))
plt.plot(freq, spec, lw=1)
for n in range(1, 4):                        # 1×~3× 마킹
    plt.axvline(n * f_rot, color='r', ls='--', alpha=.4)
plt.xlim(0, fmax)
plt.title(f"Spectrum  (Fs={fs:.0f}Hz · N={N} · Δf={df:.2f}Hz · T={T:.1f}s · {lines} lines · Hanning)")
plt.xlabel("Frequency [Hz]"); plt.ylabel("Amplitude")
plt.grid(alpha=.3); plt.tight_layout(); plt.show()
```

> [!note] 차트에서 바로 읽히는 값
> - **x축 범위** = 0 ~ fmax (상단 가드밴드 fmax~Fs/2는 버림)
> - **x축 눈금 간격** = Δf (라인 간격) · **총 점 개수** = 라인 수
> - **한 번의 스펙트럼을 얻는 데 걸린 시간** = T (측정 시간)

### 포락선 분석 (Envelope Analysis)

베어링 결함 감지에 특화. 고주파 대역의 진폭 변조를 추출.

```python
from scipy.signal import hilbert, butter, filtfilt

# 1. 고주파 대역 통과 필터
def bandpass(signal, low, high, fs):
    b, a = butter(4, [low/(fs/2), high/(fs/2)], btype='band')
    return filtfilt(b, a, signal)

filtered = bandpass(signal, 2000, 5000, fs)

# 2. 힐버트 변환으로 포락선 추출
envelope = np.abs(hilbert(filtered))

# 3. 포락선에 FFT → BPFO/BPFI 주파수 확인
freq, amp = compute_fft(envelope, fs)
```
