One-Class SVM 직사각형 임계치 & Isolation Forest

진동 특징값 2개(x, y)로 One-Class SVM을 학습해 정상 영역을 감싸는 곡선 경계를 얻고, 이를 축정렬 직사각형(Bounding Box)으로 근사해 해석 가능한 알람 임계치를 뽑아내는 과정 정리.

One-Class SVM (RBF) 정상영역 Bounding Box x·y = 선택형 특징 임계치 = min/max Isolation Forest
개요·아이디어 전체 파이프라인 특징공간·경계 nu·gamma 임계치 추출 곡선 vs 사각형 실시간 판정 Isolation Forest SVM vs IF Q&A
Overview
아이디어 — 왜 곡선 경계를 직사각형으로 바꾸나
이상탐지 모델은 "정상 영역"을 학습합니다. 문제는 그 경계가 곡선(블랙박스)이라 현장에서 쓰기 어렵다는 것. 그래서 정상 영역을 감싸는 직사각형으로 근사해, 각 특징에 익숙한 상·하한 임계치를 뽑아냅니다.

🎯 문제

진동 알람은 보통 "각 지표별 임계치(상/하한)"로 관리. 하지만 두 특징의 조합으로 봐야 정상/이상이 갈리는 경우가 많음.

🧠 학습

정상 운전 데이터만으로 One-Class SVM 학습 → 정상 데이터를 감싸는 곡선(RBF) 경계 획득. 라벨 불필요.

📐 근사

정상으로 판정된 영역의 축정렬 Bounding Box를 계산 → x·y 각각의 min/max = 4개 임계치.

🔍 해석성

결과가 "RMS 3.2~7.1, Kurtosis 2.5~4.8" 같은 사람이 읽는 숫자. 현장 엔지니어가 이해·조정 가능.

⚡ 경량 운영

운영 땐 SVM 재추론 불필요 — 4개 숫자 비교(min≤값≤max)만. PLC·엣지·대시보드 어디서나 구현.

🎛️ 유연성

x·y 축은 UI에서 사용자가 선택(RMS, Peak, Kurtosis, Crest 등 임의 2개). 설비 특성에 맞춰 조합 변경.

핵심 한 줄: One-Class SVM으로 "정상이 어디까지인가"를 데이터로 학습하고, 그 결과를 직사각형 임계치로 번역해 해석 가능하고 배포하기 쉬운 알람 규칙을 만든다.
Pipeline
전체 파이프라인
진동 원시신호부터 실시간 알람까지의 흐름. 학습은 오프라인(주기적 재학습), 판정은 온라인(경량).
학습은 무겁게(SVM), 운영은 가볍게(4개 임계치 비교) — 임계치가 학습과 판정을 잇는 산출물
Feature Space
특징 공간 · One-Class SVM 경계 · 직사각형 임계치
두 특징을 축으로 한 2D 산점도. 정상 데이터를 보라색 곡선(SVM 경계)이 감싸고, 그 곡선을 주황 직사각형(Bounding Box)이 다시 감쌉니다. 사각형의 네 변이 곧 임계치.
정상 데이터를 감싼 SVM 곡선 → 그 곡선의 축정렬 Bounding Box → 네 변이 각 특징의 상·하한 임계치
Parameters
핵심 파라미터 — nu, gamma, 그리고 스케일링
경계의 조임 정도가 곧 임계치의 넓이를 결정합니다. 잘못 잡으면 과경보(너무 조임) 또는 놓침(너무 느슨).
nu는 "정상 데이터 중 경계 밖으로 허용할 비율의 상한" — 클수록 경계가 조여짐
파라미터의미크게 하면실무 팁
nu (0~1]경계 밖 정상(오차) 허용 비율의 상한 = 서포트벡터 비율의 하한경계가 조여짐(임계치 사각형 작아짐)예상 이상치 비율로 시작(0.01~0.05)
gammaRBF 커널 폭. 한 점의 영향 반경경계가 구불구불·과적합'scale'로 시작, 과하면 낮춤
kernel경계 모양—비선형 정상영역엔 'rbf'
스케일링두 특징 단위/범위 정규화—필수. RBF는 스케일에 민감(안 하면 큰 축이 지배)
주의: StandardScaler를 학습 때 fit하고 같은 scaler로 운영 데이터를 transform해야 함. 임계치 직사각형은 원래 단위로 되돌려 저장하면 현장에서 바로 읽힘(역변환).
Threshold Extraction
임계치 추출 — 정상영역 Bounding Box (코드)
특징 공간에 격자(grid)를 깔고 SVM이 정상(+1)이라 판정한 셀들의 min/max로 직사각형을 구합니다.
1

정상 데이터의 두 특징 준비 + 스케일링

UI에서 선택된 x·y 특징만 뽑아 StandardScaler로 정규화.

2

One-Class SVM 학습

정상 데이터만으로 정상 영역을 감싸는 곡선 경계 학습.

3

격자 판정

특징 공간 전체에 그리드를 만들고 각 점이 정상(+1)/이상(−1)인지 predict.

4

Bounding Box = 임계치

정상으로 판정된 점들의 x·y 최소·최대 → 직사각형 네 변.

🐍 one_class_svm_threshold.py — 학습부터 임계치 추출까지
import numpy as np
from sklearn.svm import OneClassSVM
from sklearn.preprocessing import StandardScaler

def extract_rectangle_thresholds(normal_df, x_feat, y_feat, nu=0.03, grid=300):
    """정상 데이터로 One-Class SVM 학습 → 정상영역 Bounding Box(임계치) 반환."""
    # 1) UI에서 선택된 두 특징
    X = normal_df[[x_feat, y_feat]].to_numpy()          # shape (N, 2)

    # 2) 스케일링 (RBF는 스케일에 민감 — 필수)
    scaler = StandardScaler().fit(X)
    Xs = scaler.transform(X)

    # 3) One-Class SVM 학습 (정상 데이터만)
    oc = OneClassSVM(kernel="rbf", nu=nu, gamma="scale").fit(Xs)

    # 4) 원래 단위 특징 공간에 격자 생성
    pad_x = (X[:,0].max() - X[:,0].min()) * 0.05
    pad_y = (X[:,1].max() - X[:,1].min()) * 0.05
    xx, yy = np.meshgrid(
        np.linspace(X[:,0].min()-pad_x, X[:,0].max()+pad_x, grid),
        np.linspace(X[:,1].min()-pad_y, X[:,1].max()+pad_y, grid),
    )
    pts = np.c_[xx.ravel(), yy.ravel()]

    # 5) 격자 점을 스케일링 후 정상(+1)/이상(-1) 판정
    pred = oc.predict(scaler.transform(pts))
    normal_pts = pts[pred == 1]                          # 정상으로 판정된 영역
    if len(normal_pts) == 0:
        raise ValueError("정상 영역이 비었음 — nu/gamma 조정 필요")

    # 6) 정상영역의 축정렬 Bounding Box = 임계치 (원래 단위)
    x_min, y_min = normal_pts.min(axis=0)
    x_max, y_max = normal_pts.max(axis=0)

    return {
        x_feat: {"min": float(x_min), "max": float(x_max)},
        y_feat: {"min": float(y_min), "max": float(y_max)},
        "meta": {"nu": nu, "n_train": len(X)},
    }

# 예: RMS × Kurtosis 로 임계치 뽑기
th = extract_rectangle_thresholds(normal_df, "rms", "kurtosis", nu=0.03)
# → {'rms': {'min':2.9,'max':7.1}, 'kurtosis':{'min':2.4,'max':4.8}, ...}
대안(더 타이트): 격자 대신 학습 데이터 중 SVM이 정상(+1)으로 준 실제 포인트들의 min/max를 쓰면 사각형이 더 조여짐. 격자 방식은 "정상 영역 전체"를, 포인트 방식은 "실제 관측된 정상 범위"를 감쌈. 데이터가 경계 근처까지 고르게 있으면 둘이 비슷.
Trade-off
곡선 vs 직사각형 — 무엇을 잃는가
직사각형은 편하지만 곡선과 다릅니다. 특히 모서리 영역과 대각선으로 길쭉한 정상영역에서 오차가 큽니다.
직사각형 근사의 두 약점 — 모서리 과대포함, 대각선(상관) 정상영역에서의 헐거움
직사각형이 좋은 경우
· 두 특징이 대체로 독립적일 때
· 해석성·현장 배포가 최우선일 때
· 각 특징별 상·하한 알람이 관행일 때
· 도입 초기, 신뢰 쌓는 단계
보완책
· 상관 크면 PCA로 축 회전 후 사각형(회전된 박스 효과)
· 곡선 경계를 그대로 쓰거나 Isolation Forest 병행(다차원)
· 모서리 위험 구간엔 마진을 안쪽으로 좁힘
· 2D 사각형 + 다차원 IF 하이브리드
Runtime
실시간 판정 — 모델 없이 4번 비교
운영에선 SVM을 다시 부르지 않습니다. 저장된 임계치 4개와 min ≤ 값 ≤ max 비교만.
🐍 realtime_check.py — 임계치 적용 & 알람
def is_anomaly(x_val, y_val, th, x_feat, y_feat):
    """저장된 직사각형 임계치로 실시간 판정 (모델 로딩 불필요)."""
    xr, yr = th[x_feat], th[y_feat]
    inside = (xr["min"] <= x_val <= xr["max"]) and \
             (yr["min"] <= y_val <= yr["max"])
    reason = []
    if not (xr["min"] <= x_val <= xr["max"]):
        reason.append(f"{x_feat}={x_val:.2f} (범위 {xr['min']:.2f}~{xr['max']:.2f})")
    if not (yr["min"] <= y_val <= yr["max"]):
        reason.append(f"{y_feat}={y_val:.2f} (범위 {yr['min']:.2f}~{yr['max']:.2f})")
    return {"is_anomaly": not inside, "reasons": reason}

# 예: 실시간 특징값 판정
r = is_anomaly(8.4, 3.1, th, "rms", "kurtosis")
# → {'is_anomaly': True, 'reasons': ['rms=8.40 (범위 2.90~7.10)']}
#    어떤 특징이 왜 벗어났는지까지 바로 나옴 → 알람 메시지에 그대로 사용

⚡ 초경량

비교 4번 → 마이크로초. 수천 설비를 1초 주기로 판정해도 부담 없음.

🗣️ 설명 가능

"RMS가 상한 7.1을 초과(8.4)" 처럼 이유가 그대로 나옴 → 알람 메시지·리포트에 직결.

🔌 이식 쉬움

임계치는 그냥 숫자 4개 → PLC 래더, 엣지 C, SQL, 대시보드 어디든 이식.

Isolation Forest
Isolation Forest — 다차원 이상탐지 보완
"이상치는 몇 번의 랜덤 분할만으로 고립된다"는 원리. 2개 특징으로 제한되는 직사각형과 달리 여러 특징을 한꺼번에 다룹니다.
여러 트리의 평균 경로 길이가 짧은 샘플 = 쉽게 고립 = 이상. 트리 앙상블이라 학습·판정 빠름
🐍 isolation_forest.py — 학습 & 임계
import numpy as np
from sklearn.ensemble import IsolationForest
from sklearn.preprocessing import StandardScaler

# 다차원 특징 (2개 넘어도 됨) — 정상 데이터
X = normal_df[["rms","peak","crest_factor","kurtosis","dom_freq"]].to_numpy()
scaler = StandardScaler().fit(X)
Xs = scaler.transform(X)

iso = IsolationForest(
    n_estimators=200,        # 트리 개수(많을수록 안정)
    contamination=0.02,      # 예상 이상치 비율 → 자동 임계
    max_samples="auto",      # 트리당 샘플 수(기본 256)
    random_state=42,
).fit(Xs)

# score_samples: 낮을수록 이상. 하위 percentile을 임계로 고정
scores = iso.score_samples(Xs)
threshold = np.percentile(scores, 2)      # 하위 2% 기준

def predict(features):
    x = scaler.transform([features])
    s = iso.score_samples(x)[0]
    return {"is_anomaly": s < threshold, "score": float(s)}
contamination이 임계선의 위치를 정함 — 하위 n%를 이상으로 컷

Q&A
면접 · 실무 Q&A
Q. 왜 One-Class SVM의 곡선 경계를 그대로 안 쓰고 직사각형으로 바꿨나?
곡선 경계는 정확하지만 블랙박스라 현장에서 신뢰·조정이 어렵고 배포가 번거로움. 직사각형은 각 특징의 상·하한이라 해석 가능하고, 운영은 숫자 4개 비교로 끝나 PLC·엣지까지 이식이 쉬움. 정확도 일부를 내주고 해석성·운영성을 얻는 트레이드오프.
Q. One-Class SVM에서 nu는 정확히 무엇인가?
(0,1] 값으로, 학습 데이터 중 경계 밖으로 허용되는 비율의 상한이자 서포트벡터 비율의 하한. 클수록 경계가 조여져(정상으로 보는 영역이 좁아져) 임계치 사각형이 작아지고 과경보가 늘 수 있음. 예상 이상치 비율에서 시작해 튜닝.
Q. 스케일링을 왜 반드시 하나?
RBF 커널은 점 사이 거리를 쓰는데, 특징 단위가 다르면(예: RMS 0~10 vs 에너지 0~10000) 큰 축이 거리를 지배해 경계가 왜곡됨. StandardScaler로 정규화하고, 임계치는 원래 단위로 역변환해 저장.
Q. 직사각형이 놓치는 이상은 어떻게 보완하나?
① 두 특징 상관이 크면 PCA로 축 회전 후 사각형(회전 박스 효과) ② 곡선 경계나 Isolation Forest 병행으로 다차원·비선형 이상 커버 ③ 모서리 위험 구간은 마진을 안쪽으로 좁힘.
Q. Isolation Forest의 핵심 원리는?
특징을 랜덤하게 분할해 트리를 만들면 이상치는 적은 분할로 고립(path length 짧음)됨. 여러 트리의 평균 경로 길이를 점수화 → 짧을수록 이상. 밀도 추정 없이 "고립 난이도"로 이상을 잡아 빠르고 대용량에 강함.
Q. contamination은 무슨 역할인가?
예상 이상치 비율. 이 값으로 score 분포에서 임계선(컷)이 정해짐. 실제 이상 비율을 모르면 보수적으로 낮게 잡고, 운영하며 오탐/미탐 보고 조정.
Q. 정상 데이터만으로 학습하는 게 왜 현실적인가?
설비 결함 데이터(라벨)는 드물고 비쌈. 반면 정상 운전 데이터는 넘침. 그래서 정상만 학습해 "정상에서 벗어남"을 이상으로 보는 비지도(one-class) 접근이 PdM에서 실용적.
