# 디자인 패턴 (Design Patterns)

GoF(Gang of Four) 23가지 패턴 + 아키텍처 패턴 정리.

---

## 분류

```
디자인 패턴
├── 생성 패턴 (Creational)   → 객체 생성 방식
│   ├── Singleton
│   ├── Factory Method
│   ├── Abstract Factory
│   ├── Builder
│   └── Prototype
│
├── 구조 패턴 (Structural)   → 객체/클래스 조합 방식
│   ├── Adapter
│   ├── Decorator
│   ├── Proxy
│   ├── Facade
│   ├── Bridge
│   ├── Composite
│   └── Flyweight
│
└── 행동 패턴 (Behavioral)   → 객체 간 상호작용
    ├── Observer
    ├── Strategy
    ├── Command
    ├── Template Method
    ├── Iterator
    ├── State
    ├── Chain of Responsibility
    └── ...
```
