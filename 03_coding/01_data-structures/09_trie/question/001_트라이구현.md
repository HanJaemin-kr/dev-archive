## 문제 설명

트라이(Trie)를 구현하라.

구현할 메서드:
- `insert(word)` — 단어 삽입
- `search(word)` — 단어 존재 여부 반환
- `startsWith(prefix)` — 해당 접두사로 시작하는 단어 존재 여부 반환

## 제한사항

| 항목 | 값 |
|------|-----|
| 단어/접두사 길이 | 1 이상 2000 이하 |
| 구성 | 소문자 영문자만 |
| 메서드 호출 횟수 | 최대 3 × 10⁴ |

---

## 알고리즘 선택 분석

트라이는 문자열 탐색에 특화된 트리.

```
insert("apple"):
  root → a → p → p → l → e(isEnd=true)

search("apple") → true
search("app")   → false (isEnd 확인)
startsWith("app") → true (중간 노드 존재 여부만 확인)
```

각 노드는 자식 맵(`children`)과 단어 끝 여부(`isEnd`) 보유.

- insert: O(m) — m: 단어 길이
- search: O(m)
- startsWith: O(m)
