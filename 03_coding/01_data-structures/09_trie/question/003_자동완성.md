## 문제 설명

포털 검색창에 단어를 입력할 때, 자동완성으로 해당 단어가 유일하게 특정될 때까지 타이핑해야 한다.  
단어 목록이 주어졌을 때, 각 단어를 자동완성하기 위해 타이핑해야 하는 최소 글자 수의 합을 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 단어 수 | 1 이상 10⁵ 이하 |
| 단어 길이 | 2 이상 50 이하 |
| 소문자 영문자만 |
| 제한 시간 | 1초 |

## 입출력 예

| words | result |
|-------|--------|
| ["go","gone","guild"] | 6 |
| ["abc","def","ghi","jklm"] | 4 |

---

## 알고리즘 선택 분석

```
"go","gone","guild"
트라이:
  g → o(2개) → n → e   go: 'go'까지 2글자
                        gone: 'gon'까지 3글자
      u → i → l → d    guild: 'gu'까지 2글자
  합계: 2+3+2 = 7  ← 문제 예시와 다를 수 있음, 직접 확인
```

각 노드에 방문 횟수(count)를 저장.  
count가 1이 되는 깊이 = 그 단어만 유일하게 특정되는 지점.

트라이 insert 시 O(n × m), 결과 계산 O(n × m) → 전체 O(n × m).
