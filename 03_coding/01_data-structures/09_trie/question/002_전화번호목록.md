## 문제 설명

전화번호 목록이 주어졌을 때, 어떤 번호가 다른 번호의 접두사인지 확인하라.  
접두사인 번호가 있으면 `false`, 없으면 `true`를 반환.

## 제한사항

| 항목 | 값 |
|------|-----|
| 전화번호 수 | 1 이상 10⁶ 이하 |
| 전화번호 길이 | 1 이상 20 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| phone_book | result |
|------------|--------|
| ["119","97674223","1195524421"] | false |
| ["123","456","789"] | true |
| ["12","123","1235","567","88"] | false |

---

## 알고리즘 선택 분석

```
N = 10^6, 제한 시간 1초
```

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 정렬 후 인접 비교 | O(n log n × m) | 정렬하면 접두사는 항상 바로 앞 |
| 해시셋 | O(n × m) | 각 번호의 모든 접두사를 셋에서 조회 |
| 트라이 | O(n × m) | 직관적, 메모리 많음 |

정렬 후 인접 비교가 가장 구현이 단순하고 효율적.
