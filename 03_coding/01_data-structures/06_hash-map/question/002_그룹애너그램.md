## 문제 설명

문자열 배열 `strs`가 주어졌을 때, 애너그램끼리 묶어서 반환하라.  
결과 내 순서는 관계없음.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 10⁴ 이하 |
| 문자열 길이 | 0 이상 100 이하 |
| 소문자 영문자만 |
| 제한 시간 | 1초 |

## 입출력 예

```
입력: ["eat","tea","tan","ate","nat","bat"]
출력: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

---

## 알고리즘 선택 분석

**키 선택이 핵심.** 같은 애너그램끼리 같은 키를 가져야 함.

| 키 후보 | 방법 | 시간복잡도 |
|---------|------|-----------|
| 정렬된 문자열 | "eat".split('').sort().join('') → "aet" | O(n × k log k) |
| 알파벳 빈도 배열 | [1,0,0,...,1,0,...] → "1#0#0#...1" | O(n × k) |

정렬 방식이 구현이 단순하고 대부분의 케이스에서 충분히 빠름.
