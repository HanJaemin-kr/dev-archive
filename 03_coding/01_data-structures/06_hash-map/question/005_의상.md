# 위장 (Programmers)

## 문제 설명

코니는 매일 다른 옷을 조합하여 입는 것을 좋아합니다.

코니는 각 종류별로 최대 1가지 의상만 착용할 수 있습니다.
착용한 의상의 일부가 겹치더라도, 다른 의상이 겹치지 않거나, 혹은 의상을 추가로 더 착용한 경우에는 서로 다른 방법으로 옷을 착용한 것으로 계산합니다.
코니는 하루에 최소 한 개의 의상은 입습니다.

코니가 가진 의상들이 담긴 2차원 배열 `clothes`가 주어질 때 서로 다른 옷의 조합의 수를 return 하도록 solution 함수를 작성해주세요.

### 제한사항

- `clothes`의 각 행은 `[의상의 이름, 의상의 종류]`로 이루어져 있습니다.
- 코니가 가진 의상의 수는 1개 이상 30개 이하입니다.
- 같은 이름을 가진 의상은 존재하지 않습니다.
- 모든 문자열의 길이는 1 이상 20 이하이고 알파벳 소문자 또는 `_`로만 이루어져 있습니다.

### 입출력 예

| clothes | return |
|---|---|
| `[["yellow_hat", "headgear"], ["blue_sunglasses", "eyewear"], ["green_turban", "headgear"]]` | 5 |
| `[["crow_mask", "face"], ["blue_sunglasses", "face"], ["smoky_makeup", "face"]]` | 3 |

**예제 #1**

headgear: yellow_hat, green_turban / eyewear: blue_sunglasses → 5가지 조합

```text
1. yellow_hat
2. blue_sunglasses
3. green_turban
4. yellow_hat + blue_sunglasses
5. green_turban + blue_sunglasses
```

**예제 #2**

face 종류만 존재 → 안 입는 경우 없이 3가지만 가능

```text
1. crow_mask
2. blue_sunglasses
3. smoky_makeup
```

## 문제 요약

의상 목록이 주어질 때, 서로 다른 옷 조합의 수를 반환한다.
단, 아무것도 안 입는 경우는 제외.

### 예시

```js
[
  ["yellow_hat", "headgear"],
  ["blue_sunglasses", "eyewear"],
  ["green_turban", "headgear"]
]
```

종류별 개수

```text
headgear : 2
eyewear  : 1
```

---

## 핵심 아이디어

각 종류마다 "입는다 / 안 입는다" 선택지가 있다.

```text
headgear : yellow_hat, green_turban, 안 입음  => 3가지
eyewear  : blue_sunglasses, 안 입음           => 2가지

3 × 2 = 6
```

아무것도 안 입는 경우 1개를 빼면

```text
6 - 1 = 5
```

### 공식

```text
(종류1 개수 + 1) × (종류2 개수 + 1) × ... - 1
```

---

## 해시 풀이 (정답)

### 구현 순서

**1. 종류별 개수 세기**

```js
const map = new Map();

for (const [name, type] of clothes) {
    map.set(type, (map.get(type) || 0) + 1);
}
```

결과

```text
{ headgear => 2, eyewear => 1 }
```

**2. 경우의 수 계산**

```js
let answer = 1;

for (const count of map.values()) {
    answer *= (count + 1);
}

return answer - 1;
```

### 전체 코드

```js
function solution(clothes) {
    const map = new Map();

    for (const [name, type] of clothes) {
        map.set(type, (map.get(type) || 0) + 1);
    }

    let answer = 1;

    for (const count of map.values()) {
        answer *= (count + 1);
    }

    return answer - 1;
}
```

### 시간복잡도

```text
O(N)
```

## DFS 풀이 (비교용)

DFS는 각 종류마다 "안 입음 / 입음" 선택지를 직접 탐색한다.

### 탐색 흐름

```text
headgear
├─ 안 입음
│  └─ eyewear
│      ├─ 안 입음
│      └─ blue_sunglasses
│
├─ yellow_hat
│  └─ eyewear
│      ├─ 안 입음
│      └─ blue_sunglasses
│
└─ green_turban
   └─ eyewear
       ├─ 안 입음
       └─ blue_sunglasses
```

총 6가지 경우 → 아무것도 안 입음 1개 제외 → 5

### 코드

```js
function solution(clothes) {
    const map = new Map();

    for (const [name, type] of clothes) {
        if (!map.has(type)) {
            map.set(type, []);
        }

        map.get(type).push(name);
    }

    const categories = [...map.values()];
    let count = 0;

    function dfs(idx, selected) {
        if (idx === categories.length) {
            if (selected > 0) count++;
            return;
        }

        // 안 입는 경우
        dfs(idx + 1, selected);

        // 입는 경우
        for (const cloth of categories[idx]) {
            dfs(idx + 1, selected + 1);
        }
    }

    dfs(0, 0);

    return count;
}
```

### DFS vs 해시 비교

```text
DFS   : 모든 조합을 직접 탐색
해시  : DFS 결과를 수학 공식으로 압축

answer *= (count + 1)  ←  각 종류의 가지 수를 곱하는 것과 동일
```

## 배운 점

### 이 문제의 본질

해시 문제로 분류되지만 실제로는 조합(combination) 문제에 가깝다.

처음 보면 "DFS로 풀어야 하나?" 싶지만,
종류별로 "입는다 / 안 입는다"로 생각하면 `(개수 + 1)` 공식을 바로 떠올리는 게 핵심.

### for...of + 배열 구조 분해 할당

```js
for (const [name, type] of clothes) { ... }
```

`clothes`의 각 요소가 `["yellow_hat", "headgear"]`처럼 길이 2인 배열이기 때문에
반복마다 자동으로 아래가 실행되는 것과 같다.

```js
const [name, type] = ["yellow_hat", "headgear"];
// name = "yellow_hat"
// type = "headgear"
```

일반 방법과 비교

```js
// 일반
for (const item of clothes) {
    const name = item[0];
    const type = item[1];
}

// 구조 분해
for (const [name, type] of clothes) { ... }
```

Map 순회에서도 동일하게 사용

```js
for (const [key, value] of map) {
    console.log(key, value);
}
```

### 구조 분해 할당 정리

```js
// 배열 — [] 사용
const [name, age] = ["kim", 30];

// 객체 — {} 사용
const { name, age } = { name: "kim", age: 30 };
```

### 코테에서 자주 보는 패턴

```js
for (const [key, value] of map)   // Map 순회
const [a, b] = arr                 // 배열 분해
const { x, y } = obj               // 객체 분해
```
