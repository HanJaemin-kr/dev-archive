# 전화번호 목록 (Programmers)

## 문제 요약

전화번호 목록에서 어떤 번호가 다른 번호의 접두어(prefix)인 경우가 존재하면 `false`를 반환하고, 그렇지 않으면 `true`를 반환한다.

### 예시

```js
["119", "97674223", "1195524421"]
```

결과

```js
false
```

이유

```text
119는 1195524421의 접두어
```

---

## 처음 풀이

```js
function solution(phone_book) {
    for (let i = 0; i < phone_book.length; i++) {
        for (let j = 0; j < phone_book.length; j++) {
            if (i === j) continue;

            if (phone_book[i].includes(phone_book[j])) {
                return false;
            }
        }
    }

    return true;
}
```

### 문제점

`includes()`는 문자열 중간에 포함되어 있어도 `true`를 반환한다.

예시

```js
"1195524421".includes("955")
```

결과

```js
true
```

하지만 `955`는 접두어가 아니다.

따라서 이 문제에서는 사용할 수 없다.

---

## 수정 풀이

```js
function solution(phone_book) {
    for (let i = 0; i < phone_book.length; i++) {
        for (let j = 0; j < phone_book.length; j++) {
            if (i === j) continue;

            if (phone_book[i].startsWith(phone_book[j])) {
                return false;
            }
        }
    }

    return true;
}
```

### 시간복잡도

```text
O(N²)
```

---

## 정렬 풀이

```js
function solution(phone_book) {
    phone_book.sort();

    for (let i = 0; i < phone_book.length - 1; i++) {
        if (phone_book[i + 1].startsWith(phone_book[i])) {
            return false;
        }
    }

    return true;
}
```

### 핵심 아이디어

정렬하면 접두어를 공유하는 문자열들이 서로 인접하게 위치한다.

예시

```js
["119", "97674223", "1195524421"]
```

정렬 후

```js
["119", "1195524421", "97674223"]
```

따라서 인접한 원소끼리만 비교하면 된다.

### 시간복잡도

```text
정렬 : O(N log N)
탐색 : O(N)

총합 : O(N log N)
```

## Set(해시) 풀이

```js
function solution(phone_book) {
    const phoneSet = new Set(phone_book);

    for (const phone of phone_book) {
        let prefix = '';

        for (const digit of phone) {
            prefix += digit;

            if (prefix !== phone && phoneSet.has(prefix)) {
                return false;
            }
        }
    }

    return true;
}
```

### 동작 원리

예시

```js
phone = "1195524421"
```

접두어 생성

```text
1
11
119
1195
11955
...
```

각 접두어가 Set 안에 존재하는지 검사한다.

```js
phoneSet.has("119")
```

↓

```text
true
```

따라서 접두어 존재 → false 반환

### 시간복잡도

```text
O(N × L)

N : 전화번호 개수
L : 평균 전화번호 길이
```

---

## 배운 점

### includes vs startsWith

```js
str.includes("123")
```

* 문자열 내부 포함 여부 검사

```js
str.startsWith("123")
```

* 접두어 여부 검사

전화번호 목록 문제에서는 반드시 `startsWith()` 사용.

### 정렬의 의미

사전순 정렬 시 접두어 관계를 가진 문자열이 서로 인접하게 배치된다.

따라서 모든 쌍을 비교할 필요 없이 인접 원소만 비교하면 된다.

### 코테 관점

* 가장 직관적: 정렬 + startsWith
* 알고리즘적으로 좋은 설명: Set 활용
* 실전 제출: 정렬 풀이 추천
