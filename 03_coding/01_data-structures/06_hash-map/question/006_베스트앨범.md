# 베스트앨범 (Programmers)

## 문제 설명

스트리밍 사이트에서 장르별로 가장 많이 재생된 노래를 두 개씩 모아 베스트 앨범을 출시하려 합니다.

노래는 다음 기준으로 수록합니다.

1. 속한 노래가 많이 재생된 장르를 먼저 수록합니다.
2. 장르 내에서 많이 재생된 노래를 먼저 수록합니다.
3. 장르 내에서 재생 횟수가 같은 노래 중에서는 고유 번호가 낮은 노래를 먼저 수록합니다.

### 입출력 예

| genres | plays | return |
|---|---|---|
| `["classic", "pop", "classic", "classic", "pop"]` | `[500, 600, 150, 800, 2500]` | `[4, 1, 3, 0]` |

**설명**

- classic 총 재생: 500 + 150 + 800 = 1450
- pop 총 재생: 600 + 2500 = 3100

pop이 더 많으므로 pop 먼저.

```text
pop    → index 4 (2500), index 1 (600)
classic → index 3 (800),  index 0 (500)
```

---

## 문제 요약

`genres[i]`와 `plays[i]`가 주어질 때, 장르별 총 재생수 내림차순으로 각 장르에서 최대 2곡씩 뽑아 인덱스 배열을 반환한다.

---

## 핵심 아이디어

1. **장르별로 노래를 묶는다** → `{ classic: [{index, plays}, ...], pop: [...] }`
2. **각 장르 내부를 plays 내림차순 정렬** (동점이면 index 오름차순)
3. **장르별 총 재생수를 구해서 내림차순 정렬**
4. **정렬된 장르 순서대로 최대 2곡씩 answer에 추가**

---

## 풀이 과정 (내가 공부한 흐름)

### 1단계 — 장르별 노래 묶기

```js
const playsInfo = {};

for (let i = 0; i < genres.length; i++) {
    if (!playsInfo[genres[i]]) {
        playsInfo[genres[i]] = [];
    }

    playsInfo[genres[i]].push({
        index: i,
        plays: plays[i]
    });
}
```

결과

```js
{
  classic: [
    { index: 0, plays: 500 },
    { index: 2, plays: 150 },
    { index: 3, plays: 800 }
  ],
  pop: [
    { index: 1, plays: 600 },
    { index: 4, plays: 2500 }
  ]
}
```

### 2단계 — 장르 내부 정렬

```js
for (const genre in playsInfo) {
    playsInfo[genre].sort((a, b) => {
        if (b.plays === a.plays) {
            return a.index - b.index; // 동점이면 index 오름차순
        }
        return b.plays - a.plays; // plays 내림차순
    });
}
```

`for...in` vs `for...of`

```text
for...in  → 객체의 key를 순회할 때
for...of  → 배열/iterable의 값을 순회할 때
```

### 3단계 — 장르별 총 재생수 기준 정렬

처음엔 1등 곡 plays 기준으로 정렬했는데, 문제 기준은 **총 재생수** 기준이다.

```js
// ❌ 틀린 방법: 장르별 1등 곡 재생수 기준
let TopRatedPlaysVerGenres = {};

for (const genre in playsInfo) {
    TopRatedPlaysVerGenres[genre] = playsInfo[genre][0].plays;
}
```

```js
// ✅ 올바른 방법: 장르별 총 재생수 기준
const totalPlays = {};

for (let i = 0; i < genres.length; i++) {
    if (!totalPlays[genres[i]]) {
        totalPlays[genres[i]] = 0;
    }
    totalPlays[genres[i]] += plays[i];
}
```

### 4단계 — Object.entries()로 객체를 배열로 변환 후 정렬

```js
const genreOrder = Object.entries(totalPlays)
    .sort((a, b) => b[1] - a[1])
    .map(([genre]) => genre);
```

`Object.entries()`는 객체를 `[key, value]` 형태의 2차원 배열로 변환한다.

```js
{ classic: 1450, pop: 3100 }
→ [["classic", 1450], ["pop", 3100]]
→ sort 후: [["pop", 3100], ["classic", 1450]]
→ map 후: ["pop", "classic"]
```

`.map(([genre]) => genre)` 에서 `[genre]`는 구조 분해 할당으로 첫 번째 값만 꺼내는 것.

```js
// 첫 번째 값만
.map(([genre]) => genre)

// 두 번째 값만 (건너뜀)
.map(([, plays]) => plays)
```

### 5단계 — 장르 순서대로 최대 2곡씩

```js
for (const curGenre of genreOrder) {
    answer.push(playsInfo[curGenre][0].index);

    if (playsInfo[curGenre][1]) {
        answer.push(playsInfo[curGenre][1].index);
    }
}
```

## 최종 정답 코드

```js
function solution(genres, plays) {
    const answer = [];
    const playsInfo = {};
    const totalPlays = {};

    // 장르별 노래 묶기 + 총 재생수 누적
    for (let i = 0; i < genres.length; i++) {
        const genre = genres[i];

        if (!playsInfo[genre]) {
            playsInfo[genre] = [];
            totalPlays[genre] = 0;
        }

        playsInfo[genre].push({
            index: i,
            plays: plays[i]
        });

        totalPlays[genre] += plays[i];
    }

    // 각 장르별 plays 내림차순 정렬 (동점이면 index 오름차순)
    for (const genre in playsInfo) {
        playsInfo[genre].sort((a, b) => {
            if (b.plays === a.plays) {
                return a.index - b.index;
            }
            return b.plays - a.plays;
        });
    }

    // 총 재생수 기준으로 장르 순서 결정
    const genreOrder = Object.entries(totalPlays)
        .sort((a, b) => b[1] - a[1])
        .map(([genre]) => genre);

    // 장르 순서대로 최대 2개씩 answer에 추가
    for (const curGenre of genreOrder) {
        answer.push(playsInfo[curGenre][0].index);

        if (playsInfo[curGenre][1]) {
            answer.push(playsInfo[curGenre][1].index);
        }
    }

    return answer;
}
```

## 배운 것 정리

### 객체 key-value 정렬 패턴

```js
// 객체를 value 기준 내림차순으로 정렬하고 key만 꺼내기
Object.entries(obj)
    .sort((a, b) => b[1] - a[1])
    .map(([key]) => key);
```

코테에서 "가장 많이 나온 항목 순서"를 구할 때 항상 쓰는 패턴이다.

### 객체 순회

```js
for (const key in obj) {
    console.log(key, obj[key]);
}

for (const [key, value] of Object.entries(obj)) {
    console.log(key, value);
}
```

### 배열 구조 분해에서 건너뛰기

```js
const arr = ['pop', 2500];

const [genre] = arr;    // genre = 'pop'
const [, plays] = arr;  // plays = 2500 (첫 번째 건너뜀)
```

### 다중 정렬 기준

```js
arr.sort((a, b) => {
    if (b.plays === a.plays) {
        return a.index - b.index; // 2차 기준
    }
    return b.plays - a.plays; // 1차 기준
});
```

### 시간복잡도

```text
O(N log N) — 정렬이 지배
```
