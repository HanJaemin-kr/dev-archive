# 003. 최장 공통 접두사

- **유형**: 문자열
- **날짜**: 2026-05-17
- **소요 시간**: 분
- **결과**: 

---

## 문제 설명

문자열 배열 `strs`가 주어졌을 때, 모든 문자열의 공통 접두사 중 가장 긴 것을 반환하라.  
공통 접두사가 없으면 `""`을 반환.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 최대 200 |
| 문자열 길이 | 최대 200 |
| 제한 시간 | 1초 |

## 입출력 예

| strs | result |
|------|--------|
| ["flower","flow","flight"] | "fl" |
| ["dog","racecar","car"] | "" |
| ["a"] | "a" |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 설명 |
|------|-----------|------|
| 수직 탐색 | O(n × m) | 인덱스 0부터 한 글자씩 전체 문자열 비교 |
| 정렬 후 첫/끝 비교 | O(n log n) | 정렬하면 최대 차이가 첫·끝 원소에 집중 |

### 정렬 후 첫·끝 비교 아이디어

사전순 정렬 시 가장 다른 두 문자열은 첫 번째와 마지막.  
이 두 문자열의 공통 접두사 = 전체 공통 접두사.

```
["flower","flow","flight"] 정렬 → ["flight","flow","flower"]
첫: "flight"  끝: "flower"
공통 접두사: "fl"
```
