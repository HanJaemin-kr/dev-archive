- **소요 시간**: 분

## 문제 설명

문자열 `s`가 주어졌을 때, 영문자와 숫자만 남기고 소문자로 통일한 뒤 팰린드롬 여부를 반환하라.  
팰린드롬: 앞에서 읽으나 뒤에서 읽으나 같은 문자열.

## 제한사항

| 항목 | 값 |
|------|-----|
| 문자열 길이 | 최대 2 × 10⁵ |
| 제한 시간 | 1초 |

## 입출력 예

| s | result |
|---|--------|
| "A man, a plan, a canal: Panama" | true |
| "race a car" | false |
| " " | true |

---

## 알고리즘 선택 분석

```
N = 2×10^5, 제한 시간 1초
```

| 방법 | 시간복잡도 | 공간복잡도 |
|------|-----------|-----------|
| 정제 후 reverse 비교 | O(n) | O(n) |
| 투 포인터 (in-place) | O(n) | O(1) | ✅ |

### 투 포인터 아이디어

양 끝에서 포인터를 좁혀오며 영숫자만 비교.  
불필요한 문자는 건너뜀 → 별도 문자열 생성 없이 O(1) 공간.
