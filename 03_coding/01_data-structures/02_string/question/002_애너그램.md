# 002. 애너그램 판별

- **유형**: 문자열 / 해시맵
- **날짜**: 2026-05-17
- **소요 시간**: 분

---

## 문제 설명

두 문자열 `s`, `t`가 주어졌을 때, `t`가 `s`의 애너그램인지 반환하라.  
애너그램: 문자 구성이 동일하고 순서만 다른 문자열.

## 제한사항

| 항목 | 값 |
|------|-----|
| 문자열 길이 | 최대 5 × 10⁴ |
| 구성 | 소문자 영문자만 |
| 제한 시간 | 1초 |

## 입출력 예

| s | t | result |
|---|---|--------|
| "anagram" | "nagaram" | true |
| "rat" | "car" | false |
| "ab" | "a" | false |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 공간복잡도 |
|------|-----------|-----------|
| 정렬 후 비교 | O(n log n) | O(n) |
| 해시맵 카운팅 | O(n) | O(1) — 알파벳 26개 고정 | ✅ |

### 해시맵 아이디어

`s`의 문자 빈도를 카운트하고 `t`를 순회하며 차감.  
중간에 0 미만이 되거나 마지막에 모두 0이 아니면 false.
