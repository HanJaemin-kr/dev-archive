# 02. String (문자열)

## 1. 문자열이란?

**문자들이 순서대로 나열된 자료구조.**
JS에서 문자열은 **불변(immutable)** — 한 번 만들어지면 내용을 바꿀 수 없다.
`s[0] = 'A'`처럼 인덱스로 수정해도 조용히 실패한다.

### 도식 — 메모리 표현

```
   s = "HELLO"

   인덱스:    0   1   2   3   4
            ┌───┬───┬───┬───┬───┐
            │ H │ E │ L │ L │ O │
            └───┴───┴───┴───┴───┘
   길이 = s.length = 5
```

> 문자열은 사실상 **읽기 전용 배열**이라고 생각하면 된다.
> 변경이 필요하면 → 배열로 변환 → 수정 → 다시 join.

## 2. 핵심 성질

| 성질 | 의미 |
|------|------|
| 불변성 | 수정 시 **새 문자열**이 생성됨 |
| 인덱스 접근 | `s[i]`, `s.charAt(i)` — O(1) |
| 길이 | `s.length` — O(1) |
| 연결 | `s1 + s2` — O(n + m) (새 문자열 생성) |
| 비교 | `s1 === s2` — O(n) (내용 비교, 사전식) |

### 시간복잡도

| 연산 | 복잡도 | 비고 |
|------|--------|------|
| `s[i]`, `s.charAt(i)` | O(1) | 인덱스 접근 |
| `s.indexOf(t)` | O(n·m) | 부분 문자열 탐색 (naive) |
| `s.slice(a, b)` | O(b−a) | 새 문자열 생성 |
| `s.split(sep)` | O(n) | 배열 반환 |
| `arr.join('')` | O(n) | 문자열 합치기 |
| `s + t` | O(n + m) | 매번 새 문자열 |

> 💡 **반복 `s += c`는 O(n²) 함정.** 큰 문자열은 배열에 모아 마지막에 `.join('')`.

## 3. JS 주요 메서드

### 조회

| 메서드 | 동작 | 반환 |
|--------|------|------|
| `s.charAt(i)` | i번째 문자 | string |
| `s.charCodeAt(i)` | i번째 문자의 코드값 | number |
| `s.indexOf(t)` | t가 처음 나오는 위치 | number (없으면 -1) |
| `s.lastIndexOf(t)` | t가 마지막에 나오는 위치 | number |
| `s.includes(t)` | t 포함 여부 | boolean |
| `s.startsWith(t)` | t로 시작 | boolean |
| `s.endsWith(t)` | t로 끝남 | boolean |

### 변환

| 메서드 | 동작 |
|--------|------|
| `s.toUpperCase()` / `s.toLowerCase()` | 대/소문자 변환 |
| `s.trim()` / `s.trimStart()` / `s.trimEnd()` | 공백 제거 |
| `s.replace(a, b)` | 첫 a를 b로 교체 |
| `s.replaceAll(a, b)` | 모든 a를 b로 교체 |
| `s.repeat(n)` | n번 반복 |
| `s.padStart(n, c)` / `s.padEnd(n, c)` | 길이 n까지 c로 채움 |

### 분할 / 결합

| 메서드 | 동작 |
|--------|------|
| `s.slice(a, b)` | a부터 b 직전까지 부분 문자열 (음수 인덱스 가능) |
| `s.substring(a, b)` | slice와 유사 (음수 인덱스 불가) |
| `s.split(sep)` | sep로 분할 → 배열 |
| `arr.join(sep)` | 배열 → sep로 연결 |

### 문자 ↔ 코드

```js
'A'.charCodeAt(0)        // 65
String.fromCharCode(65)  // 'A'

// 알파벳 인덱스 (0~25)
ch.charCodeAt(0) - 'a'.charCodeAt(0)
```

## 4. 대표 패턴

### 패턴 A — 투 포인터 (양 끝에서 좁히기)

```
   "racecar" 가 팰린드롬인가?

       l                       r
       ↓                       ↓
     ┌───┬───┬───┬───┬───┬───┬───┐
     │ r │ a │ c │ e │ c │ a │ r │
     └───┴───┴───┴───┴───┴───┴───┘

     s[l] === s[r] 비교하며 l++, r--
     중앙에서 만날 때까지 모두 같으면 팰린드롬
```

용도: 팰린드롬, 뒤집기, 회문 확인

### 패턴 B — 슬라이딩 윈도우

```
   "가장 긴 중복 없는 부분 문자열"  s = "abcabcbb"

   [a]bcabcbb         → 길이 1
   [ab]cabcbb         → 길이 2
   [abc]abcbb         → 길이 3  ← 'a' 중복 전까지
    a[bca]bcbb        → 'a' 들어오면서 왼쪽 한 칸 줄임
    ...

   윈도우 [l..r] 안에 중복 없는 상태를 유지하며 r을 늘리고,
   중복이 생기면 l을 오른쪽으로 이동.
```

용도: 부분 문자열 탐색, 빈도 카운트, 최장/최단 윈도우

### 패턴 C — 해시 카운팅 (애너그램)

```
   "listen" 과 "silent" 가 애너그램인가?

       l  i  s  t  e  n           s  i  l  e  n  t
       ────────────────           ────────────────
   count:                       count:
       l:1, i:1, s:1,               s:1, i:1, l:1,
       t:1, e:1, n:1                e:1, n:1, t:1

   두 카운트가 같으면 애너그램.
   → 26-element 배열로 카운트하면 O(n) + O(26) 비교.
```

용도: 애너그램, 빈도 비교

### 패턴 D — 누적 / 빌드

```
   "최장 공통 접두사"  ["flower", "flow", "flight"]

   인덱스 0: f=f=f  ✅
   인덱스 1: l=l=l  ✅
   인덱스 2: o=o=i  ❌  →  종료

   결과: "fl"

   세로로 잘라가며 동일성 검사 (vertical scan).
```

용도: 공통 접두사, 공통 부분 문자열

## 5. 자주 하는 실수

- **`s += c` 루프 O(n²)** → 배열에 모아 `.join('')` 사용.
- **`s.length`는 UTF-16 단위** → 이모지/한자는 2칸 차지. 글자 단위로 다루려면 `[...s]` 또는 `Array.from(s)`.
- **공백/대소문자 정규화 누락** → `s.trim().toLowerCase()` 먼저 적용.
- **`replace`는 첫 번째만** → 전체 교체는 `replaceAll` 또는 `/g` 정규식.
- **숫자 비교를 문자 비교로** → `"10" < "9"`는 true (사전식). 숫자면 `Number()` 변환.
