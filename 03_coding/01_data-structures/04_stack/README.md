# 04. Stack (스택)

## 1. 스택이란?

**LIFO (Last-In, First-Out) — 마지막에 들어온 것이 가장 먼저 나간다.**
접시 쌓기, 브라우저 뒤로 가기, 함수 호출 스택이 모두 스택 구조.

### 도식 — push / pop

```
   push(1) push(2) push(3)

      ┌───┐
      │ 3 │ ← top
      ├───┤
      │ 2 │
      ├───┤
      │ 1 │ ← bottom
      └───┘

   pop() → 3 반환

      ┌───┐
      │ 2 │ ← top
      ├───┤
      │ 1 │
      └───┘
```

## 2. 핵심 연산

| 연산 | 동작 | 복잡도 |
|------|------|--------|
| `push(v)` | 맨 위에 추가 | O(1) |
| `pop()` | 맨 위 제거 + 반환 | O(1) |
| `peek()` / `top()` | 맨 위 조회 (제거 X) | O(1) |
| `isEmpty()` | 비었는지 확인 | O(1) |
| `size()` | 크기 | O(1) |

## 3. JS 구현

JS 배열로 그대로 사용 가능 (`push` / `pop`이 곧 스택 연산).

```js
const stack = [];

stack.push(1);
stack.push(2);
stack.push(3);

stack[stack.length - 1];  // 3 (peek)
stack.pop();              // 3 반환
stack.length === 0;       // false (isEmpty)
```

> ⚠️ `stack.shift()`는 O(n) — 절대 스택 연산으로 쓰지 말 것.

## 4. 대표 패턴

### 패턴 A — 짝 맞추기 (괄호, 태그)

```
   "({[]})" 의 괄호가 유효한가?

   문자: (   {   [   ]   }   )
   ────────────────────────────
   동작: push push push pop pop pop

   stack 변화:
     [(]
     [(, {]
     [(, {, []
     [(, {]     ← ']' 와 '[' 매칭
     [(]        ← '}' 와 '{' 매칭
     []         ← ')' 와 '(' 매칭

   끝에 스택이 비면 유효.
```

용도: 괄호 검증, HTML/XML 태그 검증, 수식 검사

### 패턴 B — 단조 스택 (Monotonic Stack)

**"오른쪽에서 처음으로 더 큰 수"**

```
   nums = [2, 1, 5, 3, 4],   각 원소의 "다음 큰 수"는?

   스택은 인덱스를 저장, 값이 단조 감소 유지.

   i=0, v=2:  stack=[0]                답:[?, ?, ?, ?, ?]
   i=1, v=1:  stack=[0, 1]             답:[?, ?, ?, ?, ?]
   i=2, v=5:  pop 1(v=1) → 답[1]=5
              pop 0(v=2) → 답[0]=5
              stack=[2]                답:[5, 5, ?, ?, ?]
   i=3, v=3:  stack=[2, 3]             답:[5, 5, ?, ?, ?]
   i=4, v=4:  pop 3(v=3) → 답[3]=4
              stack=[2, 4]             답:[5, 5, ?, 4, ?]

   루프 끝, 남은 인덱스는 답 = -1 (없음)
   답:[5, 5, -1, 4, -1]

   비용: O(n) — 각 원소가 한 번씩만 push/pop.
```

용도: 다음 큰/작은 수, 히스토그램 최대 직사각형, 온도 일수

### 패턴 C — 스택 두 개로 큐 구현

```
   inStack:  새 원소 push 전용
   outStack: pop 시 inStack의 모든 원소를 옮겨 담음

   enqueue(1, 2, 3):
       inStack:  [1, 2, 3]    outStack: []

   dequeue():
       outStack 비었으면 inStack을 전부 옮겨 담음:
           inStack:  []           outStack: [3, 2, 1]
       outStack.pop() → 1  ✅

   분할상환 O(1).
```

용도: 큐를 스택만으로 구현, 양방향 변환 문제

### 패턴 D — 식 계산 (후위 표기, 계산기)

```
   "3 4 + 2 *" (후위 표기)

   3  →  push       [3]
   4  →  push       [3, 4]
   +  →  pop 두 개, 3+4=7, push   [7]
   2  →  push       [7, 2]
   *  →  pop 두 개, 7*2=14, push  [14]

   최종 결과 = 14
```

용도: 후위/중위 표기 계산기, 식 트리 만들기

### 패턴 E — DFS (재귀 ≡ 스택)

```
   재귀 호출 = 시스템이 자동으로 스택을 쌓아주는 것.

   call f(3)
     ┌──────────┐
     │  f(3)    │   ← 스택 프레임이 쌓임
     ├──────────┤
     │  f(2)    │
     ├──────────┤
     │  f(1)    │
     └──────────┘

   DFS를 명시적 스택으로 풀면:
       stack = [start]
       while (stack) {
         const node = stack.pop();
         // 처리...
         stack.push(...node.children);
       }
```

용도: 트리/그래프 DFS, 재귀 → 반복 변환

## 5. 자주 하는 실수

- **`shift()` 사용** → O(n). 스택은 끝에서만 다룬다.
- **빈 스택 `pop`** → JS는 `undefined` 반환. 비교 전 `isEmpty` 체크.
- **단조 스택에서 인덱스가 아닌 값만 저장** → 거리 계산이 필요할 때 막힘.
- **괄호 매칭에서 여는/닫는 매핑 누락** → `{ ')': '(', ']': '[', '}': '{' }`처럼 명시.
