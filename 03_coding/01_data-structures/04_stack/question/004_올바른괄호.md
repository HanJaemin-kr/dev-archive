## 문제 설명

`(` 와 `)` 로만 이루어진 문자열 `s`가 주어졌을 때, 올바른 괄호 문자열이면 `true`, 아니면 `false`를 반환하라.

유효 조건:
1. 모든 `(`는 대응하는 `)`로 닫혀야 한다.
2. `)` 가 `(` 보다 먼저 나올 수 없다.

## 제한사항

| 항목 | 값 |
|------|-----|
| 문자열 길이 | 1 이상 10⁵ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| s | result |
|---|--------|
| "()()" | true |
| "(())()" | true |
| ")(" | false |
| "(()" | false |

---

## 알고리즘 선택 분석

괄호 종류가 `(` `)` 하나뿐이므로 스택 크기(열린 괄호 수)만 추적하면 된다.

```
s = "(())()"

(  → stack: 1
(  → stack: 2
)  → stack: 1
)  → stack: 0
(  → stack: 1
)  → stack: 0
끝 → stack === 0 → true
```

```
s = ")("

)  → stack이 0인데 닫힘 → 즉시 false
```

스택 자료구조로 표현하면 `push/pop`이지만,  
종류가 하나뿐이라 `count` 변수로 압축 가능.  
→ 공간복잡도 O(N) → O(1) 로 최적화됨.

> 괄호 종류가 여러 개(`({[]})`)라면 count 압축 불가 → 001_괄호유효성 참고
