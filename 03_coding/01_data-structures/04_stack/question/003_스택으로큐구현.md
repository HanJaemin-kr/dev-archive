## 문제 설명

스택 두 개만 사용해 큐(FIFO)를 구현하라.

구현할 메서드:
- `push(x)` — 원소 추가
- `pop()` — 앞 원소 제거 후 반환
- `peek()` — 앞 원소 반환 (제거 안 함)
- `empty()` — 비어있으면 true

## 제한사항

| 항목 | 값 |
|------|-----|
| push/pop/peek/empty 호출 횟수 | 최대 100 |
| 값 범위 | 1 이상 9 이하 |
| pop/peek은 항상 유효한 상태에서만 호출 |

## 입출력 예

```
push(1), push(2)
peek() → 1
pop()  → 1
empty() → false
```

---

## 알고리즘 선택 분석

스택 두 개: `inbox`(입력용), `outbox`(출력용).

```
push: inbox에 쌓기
pop/peek: outbox가 비어있으면 inbox를 전부 outbox로 옮김
          → LIFO가 두 번 뒤집혀 FIFO가 됨
```

```
push(1), push(2): inbox=[1,2]  outbox=[]
pop():  outbox 비어있음 → inbox를 옮김
        inbox=[]  outbox=[2,1]
        outbox.pop() → 1   ← FIFO 유지
pop():  outbox=[2] → outbox.pop() → 2
```

`outbox`로 옮기는 비용은 분할상환 O(1). 각 원소는 딱 한 번만 옮겨짐.
