# 002. 다음 큰 수 (Next Greater Element)

- **유형**: 스택 / 단조 스택
- **날짜**: 2026-05-17
- **소요 시간**: 분
- **결과**: 

---

## 문제 설명

정수 배열 `nums`가 주어졌을 때, 각 원소에 대해 오른쪽에서 처음으로 자신보다 큰 수를 반환하라.  
없으면 -1을 반환.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 10⁴ 이하 |
| 값 범위 | -10⁹ 이상 10⁹ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| nums | result |
|------|--------|
| [2,1,2,4,3] | [4,2,4,-1,-1] |
| [1,3,2] | [3,-1,-1] |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 브루트포스 (이중 루프) | O(n²) | 10^8 → 아슬아슬 |
| 단조 스택 | O(n) | ✅ |

### 단조 스택 아이디어

스택에 "아직 다음 큰 수를 못 찾은 인덱스"를 쌓음.  
새 원소가 스택 top보다 크면 → top의 답이 현재 원소.

```
nums = [2, 1, 2, 4, 3]

i=0: stack=[0]          (2 대기)
i=1: 1 < 2 → stack=[0,1]
i=2: 2 > 1 → ans[1]=2, 2 = 2 → stack=[0,2]
i=3: 4 > 2 → ans[2]=4, 4 > 2 → ans[0]=4 → stack=[3]
i=4: 3 < 4 → stack=[3,4]
남은 stack → ans[3]=ans[4]=-1

결과: [4, 2, 4, -1, -1]
```
