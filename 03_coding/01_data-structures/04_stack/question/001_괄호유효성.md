## 문제 설명

`(`, `)`, `{`, `}`, `[`, `]`로 이루어진 문자열 `s`가 주어졌을 때, 유효한 괄호 문자열인지 반환하라.

유효 조건:
1. 열린 괄호는 같은 종류의 닫힌 괄호로 닫혀야 한다.
2. 올바른 순서로 닫혀야 한다.

## 제한사항

| 항목 | 값 |
|------|-----|
| 문자열 길이 | 1 이상 10⁴ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| s | result |
|---|--------|
| "()" | true |
| "()[]{}" | true |
| "(]" | false |
| "([)]" | false |
| "{[]}" | true |

---

## 알고리즘 선택 분석

스택의 교과서적인 활용 문제.

```
s = "{[]}"

{  → 스택: [{]
[  → 스택: [{, []
]  → 스택 top이 [ → 매칭 → 스택: [{]
}  → 스택 top이 { → 매칭 → 스택: []
끝 → 스택 비어있음 → true
```

닫힌 괄호를 만났을 때 스택 top과 매칭되지 않으면 즉시 false.  
순회 후 스택이 비어있지 않으면 false (닫히지 않은 괄호 존재).
