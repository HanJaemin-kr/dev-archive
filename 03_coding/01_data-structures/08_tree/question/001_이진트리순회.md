## 문제 설명

이진 트리의 root가 주어졌을 때, 전위/중위/후위/레벨 순서로 순회한 결과를 각각 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 | 1 이상 100 이하 |
| 값 범위 | -100 이상 100 이하 |

## 입출력 예

```
     1
    / \
   2   3
  / \
 4   5

전위 (root→left→right): [1,2,4,5,3]
중위 (left→root→right): [4,2,5,1,3]
후위 (left→right→root): [4,5,2,3,1]
레벨:                   [1,2,3,4,5]
```

---

## 알고리즘 선택 분석

| 순회 | 방법 | 특징 |
|------|------|------|
| 전위 | DFS (재귀/스택) | root 먼저 → 복사/직렬화 |
| 중위 | DFS (재귀/스택) | 정렬된 순서 출력 (BST) |
| 후위 | DFS (재귀/스택) | root 마지막 → 삭제/계산 |
| 레벨 | BFS (큐) | 같은 깊이끼리 → 최단 거리 |
