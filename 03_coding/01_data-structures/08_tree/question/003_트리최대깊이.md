## 문제 설명

이진 트리의 root가 주어졌을 때, 최대 깊이를 반환하라.  
최대 깊이: root에서 가장 먼 leaf 노드까지의 경로에 있는 노드 수.

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 | 0 이상 10⁴ 이하 |
| 값 범위 | -100 이상 100 이하 |

## 입출력 예

```
    3          1
   / \          \
  9  20          2
    /  \
   15   7

result: 3     result: 2
```

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 공간복잡도 |
|------|-----------|-----------|
| DFS 재귀 | O(n) | O(h) — h: 트리 높이 |
| BFS 레벨 탐색 | O(n) | O(w) — w: 최대 너비 |

### DFS 재귀 아이디어

```
maxDepth(node) =
  node가 null → 0
  1 + max(maxDepth(left), maxDepth(right))
```

단 한 줄의 재귀로 해결 가능한 트리의 대표 문제.
