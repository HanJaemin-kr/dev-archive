## 문제 설명

이진 트리의 root가 주어졌을 때, 유효한 이진 탐색 트리(BST)인지 반환하라.

BST 조건:
- 왼쪽 서브트리의 모든 값 < root 값
- 오른쪽 서브트리의 모든 값 > root 값
- 각 서브트리도 BST여야 함

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 | 1 이상 10⁴ 이하 |
| 값 범위 | -2³¹ 이상 2³¹-1 이하 |
| 제한 시간 | 1초 |

## 입출력 예

```
유효한 BST:      유효하지 않은 BST:
    2                5
   / \              / \
  1   3            1   4
                      / \
                     3   6
result: true     result: false (4의 왼쪽 3이 루트 5보다 작아야 함)
```

---

## 알고리즘 선택 분석

**흔한 실수**: 부모와만 비교하면 안 됨.  
왼쪽 서브트리 전체가 루트보다 작아야 함.

### 범위 전달 방식

각 노드에 허용 범위 `[min, max]`를 전달.

```
root(5): (-∞, +∞)
  left(1): (-∞, 5)   → 1 < 5 ✅
  right(4): (5, +∞)  → 4 < 5 ❌ → false
```
