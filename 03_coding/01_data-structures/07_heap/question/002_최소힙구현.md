## 문제 설명

최소 힙을 직접 구현하라.

구현할 메서드:
- `push(val)` — 원소 추가
- `pop()` — 최솟값 제거 후 반환
- `peek()` — 최솟값 반환 (제거 안 함)
- `size()` — 현재 크기 반환

## 제한사항

| 항목 | 값 |
|------|-----|
| push/pop 호출 횟수 | 최대 10⁵ |
| 값 범위 | -10⁶ 이상 10⁶ 이하 |

---

## 알고리즘 선택 분석

힙은 완전 이진 트리를 배열로 표현.

```
인덱스 규칙 (1-based):
  부모: Math.floor(i / 2)
  왼쪽 자식: i * 2
  오른쪽 자식: i * 2 + 1
```

### push — 위로 버블업 (sift up)

```
배열 끝에 추가 → 부모보다 작으면 교환 → 반복
```

### pop — 아래로 버블다운 (sift down)

```
루트 제거 → 마지막 원소를 루트로 → 자식 중 작은 쪽과 교환 → 반복
```

두 연산 모두 O(log n).
