## 문제 설명

모든 음식의 스코빌 지수를 `K` 이상으로 만들어야 한다.  
섞는 방법: `새 음식 = 가장 안 매운 음식 + (두 번째로 안 매운 음식 × 2)`  
필요한 최소 섞기 횟수를 반환하라. 불가능하면 -1.

## 제한사항

| 항목 | 값 |
|------|-----|
| 음식 수 | 2 이상 10⁶ 이하 |
| 스코빌 지수 | 0 이상 10⁹ 이하 |
| K | 0 이상 10⁹ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| scoville | K | result |
|----------|---|--------|
| [1,2,3,9,10,12] | 7 | 2 |

---

## 알고리즘 선택 분석

```
N = 10^6, 제한 시간 1초
```

매번 최솟값 두 개를 꺼내 새 값을 넣어야 함.

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 정렬 후 배열 조작 | O(n² log n) | ❌ TLE |
| 최소 힙 | O(n log n) | ✅ |

최소 힙에서 pop/push가 O(log n) → n번 반복 → O(n log n).

JS에 내장 힙 없음 → 직접 구현 필요.
