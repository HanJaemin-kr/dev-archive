# 001. K번째로 큰 수

- **유형**: 힙 / 정렬
- **날짜**: 2026-05-17
- **소요 시간**: 분
- **결과**: 

---

## 문제 설명

정수 배열 `nums`와 정수 `k`가 주어졌을 때, k번째로 큰 수를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 10⁴ 이하 |
| k | 1 이상 배열 크기 이하 |
| 값 범위 | -10⁴ 이상 10⁴ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| nums | k | result |
|------|---|--------|
| [3,2,1,5,6,4] | 2 | 5 |
| [3,2,3,1,2,4,5,5,6] | 4 | 4 |

---

## 알고리즘 선택 분석

| 방법             | 시간복잡도      | 비고           |
| -------------- | ---------- | ------------ |
| 정렬 후 인덱스       | O(n log n) | 구현 단순        |
| 최소 힙 (크기 k 유지) | O(n log k) | k가 작을 때 유리   |
| QuickSelect    | O(n) 평균    | 가장 빠름, 구현 복잡 |

JS에 내장 힙이 없으므로, 정렬 방식이 가장 현실적.  
직접 MinHeap 구현 시 O(n log k).

### 최소 힙 아이디어

크기 k인 최소 힙 유지.  
- 힙 크기 < k → push
- 새 값 > 힙의 최솟값 → 최솟값 제거 후 push

순회 끝나면 힙의 최솟값 = k번째로 큰 수.

---

## 내 풀이

크기 k인 최소 힙을 유지하면 루트가 항상 "지금까지 본 값 중 k번째로 큰 수"가 된다.
새 값이 루트보다 크면 루트를 교체, 작거나 같으면 무시.

```js
class MinHeap {
  constructor() { this.h = []; }
  size() { return this.h.length; }
  peek() { return this.h[0]; }

  push(v) {
    this.h.push(v);
    this._up(this.h.length - 1);
  }

  pop() {
    const top = this.h[0];
    const last = this.h.pop();
    if (this.h.length) {
      this.h[0] = last;
      this._down(0);
    }
    return top;
  }

  _up(i) {
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.h[p] <= this.h[i]) break;
      [this.h[p], this.h[i]] = [this.h[i], this.h[p]];
      i = p;
    }
  }

  _down(i) {
    const n = this.h.length;
    while (true) {
      const l = i * 2 + 1, r = i * 2 + 2;
      let s = i;
      if (l < n && this.h[l] < this.h[s]) s = l;
      if (r < n && this.h[r] < this.h[s]) s = r;
      if (s === i) break;
      [this.h[s], this.h[i]] = [this.h[i], this.h[s]];
      i = s;
    }
  }
}

function findKthLargest(nums, k) {
  const heap = new MinHeap();
  for (const v of nums) {
    if (heap.size() < k) heap.push(v);
    else if (v > heap.peek()) {
      heap.pop();
      heap.push(v);
    }
  }
  return heap.peek();
}
```

### 추적 예시 (`nums = [3,2,1,5,6,4], k = 2`)

| 단계 | 값 | 힙 | 동작 |
|------|----|----|------|
| 1 | 3 | [3] | push (크기 < k) |
| 2 | 2 | [2,3] | push (크기 < k) |
| 3 | 1 | [2,3] | 1 ≤ 2, 무시 |
| 4 | 5 | [3,5] | 5 > 2, 교체 |
| 5 | 6 | [5,6] | 6 > 3, 교체 |
| 6 | 4 | [5,6] | 4 ≤ 5, 무시 |

→ 답 = `heap.peek()` = **5**

## 복잡도

- 시간: O(n log k) — 원소 n개 × 힙 연산 O(log k)
- 공간: O(k) — 힙 크기를 k로 제한

## 막혔던 점 / 오답 노트

- "k번째 **큰** 수니까 최대 힙이지" → ❌ 최소 힙이 맞다.
  크기 k짜리 최소 힙에서 루트는 "Top-K 중 가장 작은 값" = k번째 큰 수.
- 최대 힙(크기 n) 풀이는 O(n + k log n), 공간 O(n) — 최소 힙(크기 k)이 시간/공간 모두 유리.
- JS는 내장 힙이 없어서 직접 구현 필요. `_up`/`_down`에서 부모/자식 인덱스 공식 헷갈리지 않게 주의:
  - 부모: `(i - 1) >> 1`
  - 자식: `2*i + 1`, `2*i + 2`
