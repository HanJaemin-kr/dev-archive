## 문제 설명

n개의 노드와 간선 목록, 시작 노드가 주어졌을 때,  
시작 노드에서 각 노드까지의 최단 거리를 배열로 반환하라.  
도달 불가능한 노드는 -1.

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 (n) | 1 이상 10⁴ 이하 |
| 간선 수 | 0 이상 10⁵ 이하 |
| 무방향 가중치 없는 그래프 |
| 제한 시간 | 1초 |

## 입출력 예

```
n=6, edges=[[0,1],[0,2],[1,3],[2,4],[3,5]], start=0

    0
   / \
  1   2
  |   |
  3   4
  |
  5

result: [0, 1, 1, 2, 2, 3]
```

---

## 알고리즘 선택 분석

BFS는 가중치가 없는 그래프에서 최단 거리를 레벨 단위로 보장.  
dist 배열을 -1로 초기화 후 방문 시 거리 갱신.

시간복잡도: O(V+E)
