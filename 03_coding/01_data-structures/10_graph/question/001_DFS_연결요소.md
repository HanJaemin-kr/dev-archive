## 문제 설명

n개의 노드와 간선 목록이 주어졌을 때, 연결 요소(Connected Component)의 수를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 (n) | 1 이상 2000 이하 |
| 간선 수 | 0 이상 n×(n-1)/2 이하 |
| 무방향 그래프 |
| 제한 시간 | 1초 |

## 입출력 예

```
n=5, edges=[[0,1],[1,2],[3,4]]

  0-1-2   3-4  → 연결 요소 2개

result: 2
```

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| DFS | O(V+E) | 인접 리스트 기준 |
| BFS | O(V+E) | 동일 |
| Union-Find | O(α(V)×E) | 거의 O(1) 연산, 대규모 유리 |

방문 안 된 노드에서 DFS를 시작할 때마다 count++.
