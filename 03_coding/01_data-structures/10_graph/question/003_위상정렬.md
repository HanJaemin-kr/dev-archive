## 문제 설명

`n`개의 과목과 선수과목 관계 `prerequisites`가 주어졌을 때,  
모든 과목을 수강할 수 있는지 반환하라.  
`[a, b]`는 "b를 먼저 수강해야 a를 수강할 수 있다"는 의미.

## 제한사항

| 항목 | 값 |
|------|-----|
| 과목 수 (n) | 1 이상 2000 이하 |
| prerequisites 수 | 0 이상 5000 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| n | prerequisites | result |
|---|---------------|--------|
| 2 | [[1,0]] | true |
| 2 | [[1,0],[0,1]] | false (사이클 — 0→1→0) |

---

## 알고리즘 선택 분석

사이클이 있으면 모두 수강 불가 → **사이클 감지** 문제.

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| DFS + 방문 상태 (white/gray/black) | O(V+E) | 재귀 중 gray 노드 재방문 = 사이클 |
| BFS 위상 정렬 (Kahn's algorithm) | O(V+E) | 진입 차수 0인 노드부터 제거, 남으면 사이클 |

### Kahn's algorithm 아이디어

```
진입 차수(in-degree) 계산
→ 진입 차수 0인 노드를 큐에 추가
→ 큐에서 꺼내며 인접 노드 in-degree 감소
→ 0이 된 노드 큐에 추가
→ 처리한 노드 수 = n이면 사이클 없음
```
