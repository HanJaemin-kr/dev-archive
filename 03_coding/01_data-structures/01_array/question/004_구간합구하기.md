# 004. 구간 합 구하기

- **유형**: 배열 / 누적 합 (Prefix Sum)
- **날짜**: 2026-05-17
- **소요 시간**: 분
- **결과**: 

---

## 문제 설명

정수 배열 `nums`와 쿼리 배열 `queries`가 주어진다.  
각 쿼리는 `[l, r]`이며, `nums[l]`부터 `nums[r]`까지의 합을 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 (N) | 최대 10⁵ |
| 쿼리 수 (Q) | 최대 10⁵ |
| 값 범위 | -10⁴ 이상 10⁴ 이하 |
| 제한 시간 | 2초 |

## 입출력 예

```
nums    = [1, 2, 3, 4, 5]
queries = [[0,2], [1,3], [0,4]]
result  = [6, 9, 15]
```

---

## 알고리즘 선택 분석

```
N = 10^5, Q = 10^5, 제한 시간 2초
```

| 방법 | 전처리 | 쿼리 1회 | 총 복잡도 | 비고 |
|------|--------|---------|----------|------|
| 브루트포스 | O(1) | O(n) | O(n×Q) = O(10^10) | ❌ TLE |
| 누적 합 | O(n) | O(1) | O(n + Q) | ✅ |

### 누적 합 아이디어

배열을 한 번 순회해 각 위치까지의 누적 합을 미리 계산.  
이후 모든 구간 합을 O(1)에 응답.

```
nums   = [1,  2,  3,  4,  5]
prefix = [0,  1,  3,  6,  10, 15]
         ↑ prefix[0] = 0 (인덱스 편의)

[l, r] 구간 합 = prefix[r+1] - prefix[l]

[0, 2] → prefix[3] - prefix[0] = 6  - 0  = 6
[1, 3] → prefix[4] - prefix[1] = 10 - 1  = 9
[0, 4] → prefix[5] - prefix[0] = 15 - 0  = 15
```

### 주의: 누적 합의 오버플로우

값 범위 10^4, 배열 크기 10^5 → 최대 누적 합 = 10^4 × 10^5 = **10^9**  
JS `number`는 2^53까지 안전하므로 문제없음.  
Java/C++ 사용 시 `int` 대신 `long` 필요.
