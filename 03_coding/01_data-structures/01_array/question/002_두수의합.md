# 002. 두 수의 합 (Two Sum)

- **날짜**: 2026-05-17
- **소요 시간**: 분

## 문제 설명

정수 배열 `nums`와 정수 `target`이 주어졌을 때,  
합이 `target`이 되는 두 원소의 **인덱스**를 반환하라.  
정답은 반드시 하나만 존재하고, 같은 원소를 두 번 사용할 수 없다.

## 제한사항

| 항목 | 값 |
|------|-----|
| 데이터 수 (N) | 최대 10⁴ |
| 값 범위 | -10⁹ 이상 10⁹ 이하 |
| 제한 시간 | 2초 |

## 입출력 예

| nums | target | result |
|------|--------|--------|
| [2, 7, 11, 15] | 9 | [0, 1] |
| [3, 2, 4] | 6 | [1, 2] |
| [3, 3] | 6 | [0, 1] |

---

## 알고리즘 선택 분석

```
N = 10^4, 제한 시간 2초
```

| 방법 | 시간복잡도 | 공간복잡도 | 비고 |
|------|-----------|-----------|------|
| 브루트포스 (이중 루프) | O(n²) | O(1) | 10^8 → 아슬아슬 |
| 정렬 + 투 포인터 | O(n log n) | O(n) | 인덱스 보존 필요해서 번거로움 |
| 해시맵 | O(n) | O(n) | ✅ 가장 적합 |

### 해시맵 아이디어

`target - nums[i]`가 이미 나온 적 있는 값인지 Map으로 O(1) 조회.

```
target = 9, nums = [2, 7, 11, 15]

i=0: 9-2=7  → Map에 없음 → Map에 {2: 0} 저장
i=1: 9-7=2  → Map에 있음 (인덱스 0) → [0, 1] 반환
```
