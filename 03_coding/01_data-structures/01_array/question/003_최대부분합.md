# 003. 최대 부분 배열 합 (Maximum Subarray)

- **유형**: 배열 / DP / 카데인 알고리즘
- **날짜**: 2026-05-17
- **소요 시간**: 분
- **결과**: 

---

## 문제 설명

정수 배열 `nums`가 주어졌을 때, 합이 가장 큰 **연속 부분 배열**의 합을 반환하라.  
부분 배열은 최소 1개의 원소를 포함해야 한다.

## 제한사항

| 항목 | 값 |
|------|-----|
| 데이터 수 (N) | 최대 10⁵ |
| 값 범위 | -10⁴ 이상 10⁴ 이하 |
| 제한 시간 | 2초 |

## 입출력 예

| nums | result | 부분 배열 |
|------|--------|----------|
| [-2,1,-3,4,-1,2,1,-5,4] | 6 | [4,-1,2,1] |
| [1] | 1 | [1] |
| [5,4,-1,7,8] | 23 | [5,4,-1,7,8] |
| [-1,-2,-3] | -1 | [-1] |

---

## 알고리즘 선택 분석

```
N = 10^5, 제한 시간 2초
```

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 브루트포스 (모든 구간) | O(n²) | 10^10 → ❌ TLE |
| 누적 합 + 최솟값 추적 | O(n) | 가능하지만 복잡 |
| 카데인 알고리즘 | O(n) | ✅ 가장 단순 |

### 카데인 알고리즘 아이디어

현재까지의 합이 음수가 되면 버리고 새로 시작하는 게 이득.

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

cur  = 현재 부분 배열의 합
max  = 지금까지 본 최대 합

i=0: cur = max(-2, -2+(-2)) → -2   max = -2
i=1: cur = max( 1,  1+(-2)) →  1   max =  1
i=2: cur = max(-3, -3+1)    → -2   max =  1
i=3: cur = max( 4,  4+(-2)) →  4   max =  4
i=4: cur = max(-1, -1+4)    →  3   max =  4
i=5: cur = max( 2,  2+3)    →  5   max =  5
i=6: cur = max( 1,  1+5)    →  6   max =  6  ← 정답
...
```

핵심: `cur = Math.max(nums[i], cur + nums[i])`  
→ 이전 합이 음수면 버리고(nums[i]만 선택), 양수면 이어서 누적.
