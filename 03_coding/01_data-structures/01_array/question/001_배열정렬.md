# 001. 배열 정렬하기

## 문제 설명

N개의 정수가 주어졌을 때, 오름차순으로 정렬하여 출력하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 데이터 수 (N) | 최대 10⁵ (100,000) |
| 제한 시간 | 3초 |
| 값 범위 | -100,000 이상 100,000 이하 |

---

## 알고리즘 선택 분석

### 제한 조건 해석

```
N = 10^5,  제한 시간 3초
보통 1초에 약 10^8 연산 처리 가능
```

| 알고리즘 | 시간복잡도 | 연산 수 추정 | 가능 여부 |
|----------|-----------|-------------|----------|
| 버블/선택/삽입 정렬 | O(n²) | 10^10 | ❌ TLE |
| 퀵/병합/힙 정렬 | O(n log n) | 10^5 × 17 ≈ 1.7 × 10^6 | ✅ |
| 계수 정렬 | O(n + k) | 10^5 + 2×10^5 = 3×10^5 | ✅ 더 빠름 |

### 왜 계수 정렬이 가능한가?

값 범위가 **-10만 ~ 10만** (범위 k = 200,001)으로 고정되어 있음.  
범위가 유한하면 비교 없이 인덱스로 카운팅 가능 → O(n + k).

```
k = 200,001
n = 100,000
n + k = 300,001  →  매우 빠름
```

메모리: `k`개짜리 카운트 배열 → 200,001 × 4bytes ≈ **0.8 MB** (문제없음)
