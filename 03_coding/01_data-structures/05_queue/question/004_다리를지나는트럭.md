# 004. 다리를 지나는 트럭

- **유형**: 큐 / 시뮬레이션
- **출처**: 프로그래머스 (Lv.2)
- **날짜**: 2026-05-28
- **소요 시간**: 분
- **결과**: ✅

---

## 문제 설명

길이가 `bridge_length`인 다리에 트럭이 1초에 1칸씩 이동한다.
다리에는 동시에 `bridge_length`대의 트럭이 올라갈 수 있고,
다리 위 트럭들의 무게 합은 `weight`를 초과할 수 없다.

대기 트럭 목록 `truck_weights`가 주어질 때, 모든 트럭이 다리를 건너는 데 걸리는 최소 시간을 구하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| bridge_length | 1 이상 10,000 이하 |
| weight | 1 이상 10,000 이하 |
| truck_weights 길이 | 1 이상 10,000 이하 |
| 각 트럭 무게 | 1 이상 weight 이하 |

## 입출력 예

| bridge_length | weight | truck_weights | return |
|---|---|---|---|
| 2 | 10 | [7,4,5,6] | 8 |
| 100 | 100 | [10] | 101 |
| 100 | 100 | [10,10,10,10,10,10,10,10,10,10] | 110 |

---

## 알고리즘 선택 분석

다리를 길이 `bridge_length`짜리 큐로 모델링.
- 각 칸은 트럭 무게 (없으면 0).
- 매 초마다:
  1. 큐 앞(`shift`)에서 트럭 한 대 빠져나감 → 무게 차감
  2. 다음 대기 트럭을 올릴 수 있으면 `push`, 아니면 0을 `push`

큐의 길이가 항상 `bridge_length`로 유지되도록 0(빈칸)을 채워 넣는 것이 핵심.
무게 합은 매번 배열을 더하지 말고 변수로 누적 관리 → O(N+L).

---

## 내 풀이

```js
function solution(bridge_length, weight, truck_weights) {
    let count = 0;
    let bridge_queue = new Array(bridge_length).fill(0);
    let bridge_weight = 0;

    while (truck_weights.length > 0 || bridge_weight > 0) {
        count++; // 순서 체크 들어오고

        bridge_weight -= bridge_queue.shift(); // 앞차 먼저 나가고
        if (
            truck_weights.length > 0 &&
            bridge_weight + truck_weights[0] <= weight
        ) {
            let cur = truck_weights.shift();
            bridge_queue.push(cur); // 뒷차 들어옴
            bridge_weight += cur;
        } else {
            bridge_queue.push(0);
        }
    }

    return count;
}
```

### 흐름 (예: bridge_length=2, weight=10, [7,4,5,6])

```
t=1: queue=[0,7], onBridge=7,  대기=[4,5,6]
t=2: queue=[7,0], onBridge=7   (7+4>10이라 못 올림)
t=3: queue=[0,4], onBridge=4   (7 내려감, 4 올라감)
t=4: queue=[4,5], onBridge=9
t=5: queue=[5,0], onBridge=5   (5+6>10이라 못 올림)
t=6: queue=[0,6], onBridge=6
t=7: queue=[6,0], onBridge=6
t=8: queue=[0,0], onBridge=0   → 종료
→ 8
```

## 복잡도

- 시간: O((N+L) · L) — `shift()`가 O(L)이라 다리 길이만큼 비용 추가
- 공간: O(L)

> 다리 길이/트럭 수 모두 ≤ 10,000 이라 통과.
> 입력이 더 크면 인덱스 포인터 큐로 교체해 O(N+L)로 만들 수 있음.

## 막혔던 점 / 오답 노트

- **종료 조건**: `truck_weights.length === 0`만 보면 안 됨. 마지막 트럭이 다리 위에 남아있는 동안에도 시간이 흘러야 함 → `bridge_weight > 0`까지 OR로 묶기.
- **무게 합 재계산 금지**: 매 틱마다 `reduce`로 더하면 O(L²) → 누적 변수로 +/− 처리.
- **순서**: 같은 틱 안에서 "앞차 내려가기 → 뒷차 올리기" 순서. 반대로 하면 같은 칸에 두 트럭이 겹쳐 무게 계산이 어긋남.
