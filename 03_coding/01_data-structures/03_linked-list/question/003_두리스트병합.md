- **유형**: 연결 리스트 / 투 포인터
- **날짜**: 2026-05-17
- **소요 시간**: 분

---

## 문제 설명

정렬된 두 연결 리스트 `l1`, `l2`를 하나의 정렬된 리스트로 병합하여 반환하라.  
새 노드를 만들지 않고 기존 노드를 재활용해야 한다.

## 제한사항

| 항목 | 값 |
|------|-----|
| 각 리스트 노드 수 | 0 이상 50 이하 |
| 값 범위 | -100 이상 100 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| l1 | l2 | result |
|----|-----|--------|
| 1→2→4 | 1→3→4 | 1→1→2→3→4→4 |
| [] | [] | [] |
| [] | 0 | 0 |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 공간복잡도 |
|------|-----------|-----------|
| 반복문 + 더미 헤드 | O(n+m) | O(1) | ✅ |
| 재귀 | O(n+m) | O(n+m) — 콜스택 |

### 더미 헤드 아이디어

결과 리스트의 head를 더미 노드로 시작하면 엣지 케이스 처리가 쉬워짐.  
두 리스트를 비교하며 작은 쪽을 결과에 연결, 남은 리스트는 그대로 이어붙임.
