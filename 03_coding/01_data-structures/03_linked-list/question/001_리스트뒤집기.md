## 문제 설명

단방향 연결 리스트의 head가 주어졌을 때, 리스트를 뒤집어 새 head를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 | 0 이상 5000 이하 |
| 값 범위 | -5000 이상 5000 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| 입력 | 출력 |
|------|------|
| 1→2→3→4→5 | 5→4→3→2→1 |
| 1→2 | 2→1 |
| [] | [] |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 공간복잡도 |
|------|-----------|-----------|
| 배열로 변환 후 역순 연결 | O(n) | O(n) |
| 반복문 — 포인터 3개 | O(n) | O(1) | ✅ |
| 재귀 | O(n) | O(n) — 콜스택 |

### 반복문 아이디어

`prev`, `cur`, `next` 포인터 3개로 in-place 뒤집기.

```
초기:  null ← prev  cur → next
       null    [1] → [2] → [3]

step1: cur.next = prev → [1].next = null
       prev = cur, cur = next
       null ← [1]  [2] → [3]

step2: [2].next = [1]
       null ← [1] ← [2]  [3]
...
최종 head = prev
```
