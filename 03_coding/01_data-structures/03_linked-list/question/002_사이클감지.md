## 문제 설명

연결 리스트의 head가 주어졌을 때, 사이클이 존재하면 `true`, 없으면 `false`를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 노드 수 | 최대 10⁴ |
| 제한 시간 | 1초 |

## 입출력 예

| 입력 | 사이클 | result |
|------|--------|--------|
| 3→2→0→-4→(2로 연결) | 있음 | true |
| 1→2→(1로 연결) | 있음 | true |
| 1 | 없음 | false |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 공간복잡도 |
|------|-----------|-----------|
| Set으로 방문 추적 | O(n) | O(n) |
| 플로이드 순환 감지 (토끼와 거북이) | O(n) | O(1) | ✅ |

### 플로이드 알고리즘

`slow`는 1칸, `fast`는 2칸씩 이동.  
사이클이 있으면 언젠가 반드시 만남. 없으면 `fast`가 null에 도달.

```
3 → 2 → 0 → -4
        ↑         ↓
        └─────────┘
slow: 3→2→0→-4→2→0 ...
fast: 3→0→2→0→2→0 ...
→ 같은 노드에서 만남
```
