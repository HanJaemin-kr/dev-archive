# 002. 슬라이딩 윈도우 최댓값

- **유형**: 슬라이딩 윈도우 / 덱
- **날짜**: 2026-05-17
- **소요 시간**: 분
- **결과**: 

---

## 문제 설명

정수 배열 `nums`와 윈도우 크기 `k`가 주어졌을 때,  
크기 k인 슬라이딩 윈도우의 최댓값을 모두 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 10⁵ 이하 |
| 값 범위 | -10⁴ 이상 10⁴ 이하 |
| k | 1 이상 배열 크기 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| nums | k | result |
|------|---|--------|
| [1,3,-1,-3,5,3,6,7] | 3 | [3,3,5,5,6,7] |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 브루트포스 | O(n×k) | k 크면 TLE |
| 단조 덱 | O(n) | ✅ |

### 단조 덱 (감소 단조 덱)

덱에 **인덱스**를 저장. 앞에서 꺼낼 때 윈도우 범위 벗어나면 제거.  
뒤에서 넣을 때 현재 값보다 작은 인덱스 제거(어차피 최대값 후보가 아님).

```
덱의 앞 = 현재 윈도우 최댓값 인덱스
```
