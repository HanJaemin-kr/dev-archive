## 문제 설명

양수로 이루어진 배열 `nums`와 `target`이 주어졌을 때,  
합이 정확히 `target`인 연속 부분 배열의 수를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 10⁵ 이하 |
| 원소 | 1 이상 10⁴ 이하 (양수) |
| target | 1 이상 10⁹ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| nums | target | result |
|------|--------|--------|
| [1,2,3,4,5] | 5 | 2 |
| [1,1,1,1,1] | 3 | 3 |

---

## 알고리즘 선택 분석

원소가 **양수만**이면 투 포인터 가능.  
(음수 포함 시 누적 합 + 해시맵 방식 필요)

```
sum < target → right 확장
sum > target → left 축소
sum = target → count++, right 확장
```

O(n) — 각 포인터가 최대 n번 이동.
