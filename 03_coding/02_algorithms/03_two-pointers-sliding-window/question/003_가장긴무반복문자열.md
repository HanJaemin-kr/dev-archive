## 문제 설명

문자열 `s`가 주어졌을 때, 문자 중복 없이 구성된 가장 긴 부분 문자열의 길이를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 문자열 길이 | 0 이상 5 × 10⁴ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| s | result |
|---|--------|
| "abcabcbb" | 3 |
| "bbbbb" | 1 |
| "pwwkew" | 3 |
| "" | 0 |

---

## 알고리즘 선택 분석

가변 크기 슬라이딩 윈도우.  
Map으로 각 문자의 마지막 인덱스를 저장.

```
s = "abcabcbb"
left=0

a(0): map={a:0}        len=1
b(1): map={a:0,b:1}    len=2
c(2): map={...c:2}     len=3
a(3): a가 left(0) 이상에 있음 → left=1, map{a:3} len=3
b(4): b가 left(1) 이상에 있음 → left=2, map{b:4} len=3
...
```
