# 03. Two Pointers & Sliding Window (투 포인터 / 슬라이딩 윈도우)

## 1. 투 포인터 / 슬라이딩 윈도우란?

**두 개의 인덱스를 동시에 움직이며 O(n)에 푸는 기법.**
브루트포스 O(n²) 의 자연스러운 최적화. 핵심은 "한 번 지나간 인덱스는 다시 돌아오지 않는다".

### 도식 — 양 끝 vs 한 방향

```
   양 끝 좁히기 (Two Pointers):

       lo →                       ← hi
       ▼                            ▼
     ┌───┬───┬───┬───┬───┬───┬───┐
     │ a │ b │ c │ d │ e │ f │ g │
     └───┴───┴───┴───┴───┴───┴───┘
       정렬된 배열에서 합 / 팰린드롬


   한 방향 가변 윈도우 (Sliding Window):

       l ────→ r
       ▼       ▼
     ┌───┬───┬───┬───┬───┬───┬───┐
     │ a │ b │ c │ d │ e │ f │ g │
     └───┴───┴───┴───┴───┴───┴───┘
            윈도우 [l..r] 안의 상태를 유지하며 r 전진,
            조건 어기면 l 전진
```

## 2. 시간복잡도

| 연산 | 복잡도 | 비고 |
|------|--------|------|
| 양 끝 좁히기 | O(n) | 각 포인터가 최대 n번 이동 |
| 가변 윈도우 | O(n) | l, r 각각 최대 n번 |
| 고정 윈도우 | O(n) | 매 step 상수 시간 |
| 단조 덱 | O(n) | 각 원소 push/pop 1회 |

> 공간: O(1) 또는 보조 해시맵/덱 시 O(k).

## 3. JS 구현 템플릿

### 양 끝 좁히기

```js
function twoSumSorted(arr, target) {
  let lo = 0, hi = arr.length - 1;
  while (lo < hi) {
    const s = arr[lo] + arr[hi];
    if (s === target) return [lo, hi];
    if (s < target) lo++;
    else hi--;
  }
  return [-1, -1];
}
```

### 가변 슬라이딩 윈도우

```js
function longestUniqueSubstring(s) {
  const map = new Map();
  let left = 0, best = 0;
  for (let r = 0; r < s.length; r++) {
    const ch = s[r];
    if (map.has(ch) && map.get(ch) >= left) {
      left = map.get(ch) + 1;
    }
    map.set(ch, r);
    best = Math.max(best, r - left + 1);
  }
  return best;
}
```

### 고정 크기 윈도우

```js
// 크기 k 의 부분합 최댓값
function maxSumK(arr, k) {
  let sum = 0;
  for (let i = 0; i < k; i++) sum += arr[i];
  let best = sum;
  for (let i = k; i < arr.length; i++) {
    sum += arr[i] - arr[i - k];
    best = Math.max(best, sum);
  }
  return best;
}
```

## 4. 대표 패턴

### 패턴 A — 양 끝 (Two Pointers)

```
   정렬된 배열에서 합 = target

       lo                       hi
       ▼                         ▼
     [1, 2, 4, 7, 11, 15],  target = 9

     sum < target → lo++
     sum > target → hi--
     sum = target → 답
```

```
   팰린드롬 검사:

       l                       r
       ▼                       ▼
     [r, a, c, e, c, a, r]

     s[l] === s[r] 확인하며 l++, r--
     중앙에서 만날 때까지 모두 같으면 OK.
```

용도: 정렬된 배열의 합/차, 팰린드롬, 두 배열 병합

### 패턴 B — 가변 윈도우 + 조건 충족

```
   "가장 긴 무중복 부분 문자열"  s = "abcabcbb"

   [a]bcabcbb        l=0, r=0,  Map={a:0}
   [ab]cabcbb        l=0, r=1,  Map={a:0,b:1}
   [abc]abcbb        l=0, r=2,  Map={a:0,b:1,c:2}   ← 최대 길이 3
    a[bca]bcbb       l=1, r=3   ← a 중복, l을 a 이전 위치 다음으로
    ab[cab]cbb       l=2, r=4
    ...

   윈도우 안에 조건(중복 없음)을 유지하며 r 전진,
   깨지면 l 전진.
```

용도: 무중복 부분문자열, 합 ≥ target 최소 길이, K개 종류 윈도우

### 패턴 C — 고정 크기 윈도우

```
   크기 k 의 부분합 최댓값

   [1, 2, 3, 4, 5],  k = 3

   윈도우  합
   [1,2,3] 6
    [2,3,4] 9     ← 한 칸 이동: -1 + 4
     [3,4,5] 12   ← +5 -2

   매 이동마다 추가/제거 1번씩 → O(n)
```

용도: 평균, 부분합, 빈도 비교 (애너그램 검색)

### 패턴 D — 단조 덱 (Monotonic Deque)

```
   "윈도우 크기 k 의 최댓값"

   nums = [1, 3, -1, -3, 5, 3, 6, 7],  k = 3

   덱의 앞 = 현재 윈도우 최댓값 인덱스.
   덱 안의 값은 단조 감소.

   i=0 (1):  d=[0]
   i=1 (3):  3 > 1 → 0 제거,  d=[1]
   i=2 (-1): d=[1, 2]                  → 윈도우 [1,3,-1], 답=3
   i=3 (-3): 윈도우 진입,  d=[1,2,3]   → 답=3
   i=4 (5):  5보다 작은 값 인덱스 모두 제거, d=[4] → 답=5
   ...
```

용도: 슬라이딩 윈도우 최대/최소

## 5. 자주 하는 실수

- **음수 포함인데 투 포인터** → 양수일 때만 단조성 보장. 음수 있으면 누적합 + 해시 필요.
- **윈도우 조건 갱신 시점** — 추가/제거 시점이 일관되지 않으면 한 칸 어긋남.
- **`l` 갱신을 잊고 무한 루프** → 조건 위반 시 반드시 `l` 전진.
- **고정 윈도우에서 초기화 누락** → 첫 k개 합을 먼저 만들고 나서 슬라이드 시작.
- **단조 덱에서 인덱스 대신 값만 저장** → 윈도우 범위 벗어남 체크가 안 됨.
- **`l = map.get(ch) + 1` 에서 `map.get` 이 윈도우 바깥일 때** → `>= left` 조건 필수.

## 7. 한 줄 요약

> **"두 인덱스가 만나거나 끝에 닿을 때까지 한 방향으로 흐른다 — O(n)."**
>
> 정렬되어 있고 양수면 양 끝, 조건 유지면 가변 윈도우, 최대/최소면 단조 덱.
> 브루트포스 O(n²) 를 보고 한 번은 의심해볼 도구.
