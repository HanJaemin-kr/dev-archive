## 문제 설명

지원자 정보 `info`와 조건 `query`가 주어졌을 때, 각 조건에 맞는 지원자 수를 반환하라.  
`-`는 조건 없음을 의미.

## 제한사항

| 항목 | 값 |
|------|-----|
| info 수 | 1 이상 5 × 10⁴ 이하 |
| query 수 | 1 이상 10⁵ 이하 |
| 제한 시간 | 3초 |

## 입출력 예

```
info:  ["java backend junior pizza 150", "python frontend senior chicken 210", ...]
query: ["java and backend and junior and pizza 100", "python and frontend and senior and chicken 200", ...]
result: [1, 1, ...]
```

---

## 알고리즘 선택 분석

```
query × info = 10^5 × 5×10^4 = 5×10^9 → ❌ 브루트포스 TLE
```

**전처리 + 이진 탐색**:
- 가능한 모든 조건 조합(2^4=16가지)을 키로 Map에 점수 배열 저장
- 각 배열을 정렬
- query 시 해당 키의 배열에서 이진 탐색(lower bound)으로 count
