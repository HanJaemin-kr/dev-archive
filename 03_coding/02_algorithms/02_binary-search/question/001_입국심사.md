## 문제 설명

`n`명이 입국심사를 받을 때, 심사관별 소요 시간 `times`가 주어진다.  
모든 사람이 심사를 받는 데 걸리는 최소 시간을 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 심사관 수 | 1 이상 10⁵ 이하 |
| n (사람 수) | 1 이상 10⁹ 이하 |
| 심사 시간 | 1 이상 10⁹ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| n | times | result |
|---|-------|--------|
| 6 | [7,10] | 28 |

---

## 알고리즘 선택 분석

```
n = 10^9 → 시뮬레이션 불가
```

**파라메트릭 서치**: "시간 T 안에 n명을 처리할 수 있는가?" 를 이진 탐색.

```
T시간 안에 처리 가능한 인원 = Σ floor(T / times[i])

lo = 1, hi = min(times) * n
mid = (lo+hi)/2
  가능(처리 인원 >= n) → hi = mid
  불가(처리 인원 < n)  → lo = mid + 1
```
