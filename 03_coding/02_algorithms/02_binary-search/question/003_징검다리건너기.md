## 문제 설명

`stones` 배열의 각 원소는 해당 돌을 밟을 수 있는 횟수.  
한 번 밟을 때마다 1씩 감소, 0이 되면 건너뛰어야 함.  
최대 `k`칸 뛸 수 있을 때, 건널 수 있는 최대 인원을 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| stones 길이 | 1 이상 2 × 10⁵ 이하 |
| stones 원소 | 1 이상 2 × 10⁸ 이하 |
| k | 1 이상 stones 길이 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| stones | k | result |
|--------|---|--------|
| [2,4,5,3,2,1,4,2,5,1] | 3 | 3 |

---

## 알고리즘 선택 분석

```
"n명이 건널 수 있는가?" → 파라메트릭 서치
```

n명이 건너면 각 돌이 n만큼 소모됨.  
`stones[i] - n < 0`이면 그 돌은 사용 불가.  
k개 연속으로 사용 불가 돌이 나오면 건널 수 없음.

```
lo = 1, hi = max(stones)
mid → 건널 수 있으면 lo = mid+1, 없으면 hi = mid
```
