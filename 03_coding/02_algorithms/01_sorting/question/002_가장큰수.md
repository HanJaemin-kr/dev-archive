## 문제 설명

정수 배열 `numbers`가 주어졌을 때, 원소들을 이어 붙여 만들 수 있는 가장 큰 수를 문자열로 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 100 이하 |
| 원소 값 | 0 이상 1000 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| numbers | result |
|---------|--------|
| [6,10,2] | "6210" |
| [3,30,34,5,9] | "9534330" |

---

## 알고리즘 선택 분석

단순 숫자 정렬이 아님. **이어 붙인 결과 기준**으로 정렬해야 함.

```
비교 기준: a+b vs b+a (문자열 이어붙이기)

"3"+"30" = "330"
"30"+"3" = "303"
"330" > "303" → 3이 앞에 와야 함

"9"+"5" = "95"
"5"+"9" = "59"
"95" > "59" → 9가 앞
```

`(a, b) => (b+a) - (a+b)` 문자열 비교로 커스텀 정렬.

엣지 케이스: 모두 0이면 "000..." → "0" 반환.
