## 문제 설명

회의 시작/종료 시간 목록이 주어졌을 때, 한 회의실에서 진행할 수 있는 최대 회의 수를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 회의 수 | 1 이상 10⁵ 이하 |
| 시작/종료 시간 | 0 이상 10⁵ 이하 |
| 시작 시간 = 종료 시간인 회의도 포함 |
| 제한 시간 | 1초 |

## 입출력 예

| meetings | result |
|----------|--------|
| [[1,4],[3,5],[0,6],[5,7],[3,8],[5,9],[6,10],[8,11],[8,12],[2,13],[12,14]] | 4 |

---

## 알고리즘 선택 분석

**종료 시간 기준 정렬** → 가장 일찍 끝나는 회의를 먼저 선택하는 그리디.

```
종료 기준 정렬: [1,4],[3,5],[0,6],[5,7],[3,8],[5,9],[6,10],[8,11],[8,12],[2,13],[12,14]

현재 끝 시간 = 0
[1,4]:  1 >= 0 → 선택, end=4, count=1
[3,5]:  3 < 4  → 스킵
[0,6]:  0 < 4  → 스킵
[5,7]:  5 >= 4 → 선택, end=7, count=2
...
```

**왜 종료 시간 기준인가?**  
시작 시간 기준이면 긴 회의를 먼저 선택할 수 있어 다음 회의를 많이 막음.  
종료 시간 기준이면 최대한 빨리 끝내서 다음 회의 기회를 남김.
