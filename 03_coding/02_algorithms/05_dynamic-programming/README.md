# 05. Dynamic Programming (동적 계획법)

## 1. DP란?

**중복되는 부분 문제 + 최적 부분 구조** 를 가진 문제를, 한 번 계산한 결과를 저장해 재사용하는 기법.
순수 재귀의 지수 시간을 다항 시간으로 끌어내린다.

### 도식 — 중복 부분 문제

```
   순수 재귀 fib(5):

                fib(5)
              /        \
          fib(4)       fib(3)    ← fib(3) 두 번 계산
         /     \       /    \
      fib(3) fib(2) fib(2) fib(1)
       ...     ...   ...

   같은 입력에 대해 같은 계산을 반복 → O(2^n)

   DP: 한 번 푼 부분 문제는 메모 → O(n)
```

### DP가 적용 가능한 조건

```
   1. 최적 부분 구조 (Optimal Substructure)
        → 부분 문제의 최적해로 전체 최적해를 구성할 수 있다.

   2. 중복 부분 문제 (Overlapping Subproblems)
        → 같은 부분 문제가 여러 번 등장한다.
```

## 2. Top-down vs Bottom-up

| 항목 | Top-down (메모이제이션) | Bottom-up (테뷸레이션) |
|------|----------------------|----------------------|
| 방향 | 큰 문제 → 작은 문제 | 작은 문제 → 큰 문제 |
| 구현 | 재귀 + 메모 | 반복문 + 배열 |
| 호출 비용 | 함수 호출 오버헤드 | 없음 (보통 더 빠름) |
| 스택 | 재귀 깊이 만큼 사용 | O(1) (배열 외) |
| 가독성 | 점화식과 1:1 | 인덱스 순서 신경 써야 함 |
| 부분 계산 | 필요한 것만 | 전체 계산 |

> **n 이 크면 (≥ 10⁴) 보통 Bottom-up**. 재귀 깊이 한계 회피.

## 3. JS 구현 템플릿

### 1D DP

```js
// 계단 오르기: 한 번에 1 또는 2 칸
function climb(n) {
  const dp = new Array(n + 1).fill(0);
  dp[0] = 1; dp[1] = 1;
  for (let i = 2; i <= n; i++) dp[i] = dp[i - 1] + dp[i - 2];
  return dp[n];
}
```

### 2D DP

```js
// LCS (최장 공통 부분 수열)
function lcs(s1, s2) {
  const n = s1.length, m = s2.length;
  const dp = Array.from({ length: n + 1 }, () => new Array(m + 1).fill(0));
  for (let i = 1; i <= n; i++) {
    for (let j = 1; j <= m; j++) {
      if (s1[i - 1] === s2[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
      else dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
    }
  }
  return dp[n][m];
}
```

### 공간 최적화 (1D 압축)

```js
// 0/1 배낭 - 1D 역방향 순회
function knapsack(weights, values, cap) {
  const dp = new Array(cap + 1).fill(0);
  for (let i = 0; i < weights.length; i++) {
    for (let w = cap; w >= weights[i]; w--) {  // ⚠️ 역방향
      dp[w] = Math.max(dp[w], dp[w - weights[i]] + values[i]);
    }
  }
  return dp[cap];
}
```

> ⚠️ 0/1 배낭에서 정방향 순회하면 같은 물건을 여러 번 선택하게 됨 → 무한 배낭이 되어버림.

## 4. 대표 패턴

### 패턴 A — 1D DP

```
   상태 dp[i] = "i번째까지 고려했을 때의 최적해"

   계단 오르기:  dp[i] = dp[i-1] + dp[i-2]
   LIS:         dp[i] = max(dp[j] + 1) for j < i, arr[j] < arr[i]
   동전 거스름돈:  dp[i] = min(dp[i - coin] + 1) for coin in coins
```

용도: 피보나치류, LIS, 동전 거스름돈

### 패턴 B — 2D DP (두 문자열/배열 비교)

```
   dp[i][j] = "s1[0..i-1] 과 s2[0..j-1] 의 ..."

           ""  a  c  e
        ┌──┬──┬──┬──┐
     ""  │ 0│ 0│ 0│ 0│
     a  │ 0│ 1│ 1│ 1│
     b  │ 0│ 1│ 1│ 1│
     c  │ 0│ 1│ 2│ 2│
     d  │ 0│ 1│ 2│ 2│
     e  │ 0│ 1│ 2│ 3│  ← LCS = 3 ("ace")
        └──┴──┴──┴──┘

   현재 칸 = 좌상단(매치) 또는 좌/위 중 큰 값(미매치)
```

용도: LCS, 편집 거리, 두 배열 정렬 일치도

### 패턴 C — 0/1 배낭 vs 무한 배낭

```
   dp[i][w] = "i 번째 물건까지, 무게 w 이하에서 최대 가치"

   넣지 않음:  dp[i-1][w]
   넣음:       dp[i-1][w - weights[i]] + values[i]
   dp[i][w] = max(둘)

   1D 압축:
     - 0/1 배낭 → w 역방향 순회 (이전 i의 상태 사용)
     - 무한 배낭 → w 정방향 순회 (현재 i의 상태도 사용)
```

용도: 자원 배분, 부분집합 합, 동전 거스름돈

### 패턴 D — 격자 DP

```
   "정수 삼각형 / 경로의 최댓값"

           [7]
          [3,8]
         [8,1,0]
        [2,7,4,4]
       [4,5,2,6,5]

   bottom-up: 아래에서 위로 누적
     dp[i][j] = triangle[i][j] + max(dp[i+1][j], dp[i+1][j+1])

   답 = dp[0][0]

   공간 최적화: 한 행 (또는 triangle 자체) 만으로 가능.
```

용도: 경로 합, 격자 이동, 미로 최단거리

### 패턴 E — 비트마스크 / 트리 DP (한 줄)

```
   비트마스크 DP: 부분집합 상태를 비트로 압축 → 외판원 문제, 집합 분할
   트리 DP:       트리 위에서 자식 DP 합산 → 루트~리프 경로, 트리의 지름
```

용도: 작은 n (≤ 20) 의 모든 부분집합 탐색, 트리 구조 최적해

## 5. 자주 하는 실수

- **점화식 정의 모호** → "dp[i] 가 정확히 무엇을 의미하는가?" 를 한 문장으로 못 쓰면 진도 X.
- **초기값 (베이스) 오류** → `dp[0]` 의미를 잘못 잡으면 전체가 어긋남.
- **0/1 배낭에서 정방향 순회** → 같은 물건 여러 번 선택. 무조건 역방향.
- **메모이제이션 키** — 다차원이면 `${i},${j}` 또는 2D 배열. 객체 키는 자동 문자열화 주의.
- **인덱스 오프바이원** — `dp[i][j]` 가 1-base인지 0-base인지 일관성 유지.
- **재귀 + 메모인데 깊이 한계** — n ≥ 10⁵ 이면 Bottom-up.

## 7. 한 줄 요약

> **"같은 부분 문제를 두 번 풀고 있다면 DP."**
>
> 핵심은 1) 상태 정의, 2) 점화식, 3) 베이스. 이 3개만 정확하면 코드는 자동.
> 1D는 점화식 그대로, 2D는 표 그려가며, 격자는 bottom-up이 직관적.
