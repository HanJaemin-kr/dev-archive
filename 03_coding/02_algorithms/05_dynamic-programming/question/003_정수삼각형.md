## 문제 설명

삼각형 꼭대기에서 바닥까지 이동할 때, 거치는 수들의 합의 최댓값을 반환하라.  
각 칸에서 아래 왼쪽 또는 오른쪽으로만 이동 가능.

## 제한사항

| 항목 | 값 |
|------|-----|
| 삼각형 높이 | 1 이상 500 이하 |
| 각 원소 | 0 이상 9999 이하 |
| 제한 시간 | 1초 |

## 입출력 예

```
triangle = [[7],[3,8],[8,1,0],[2,7,4,4],[4,5,2,6,5]]

       7
      3 8
     8 1 0
    2 7 4 4
   4 5 2 6 5

result: 30  (7→8→1→7→5)
```

---

```

위 행부터: dp[i][j] = triangle[i][j] + max(dp[i+1][j], dp[i+1][j+1])
```
