# 001. 최장 공통 부분 수열 (LCS)

- **유형**: DP

---

## 문제 설명

두 문자열 `s1`, `s2`가 주어졌을 때, 최장 공통 부분 수열(LCS)의 길이를 반환하라.  
부분 수열: 순서를 유지하되 연속일 필요 없음.

## 제한사항

| 항목 | 값 |
|------|-----|
| 문자열 길이 | 1 이상 1000 이하 |
| 소문자 영문자 |
| 제한 시간 | 1초 |

## 입출력 예

| s1 | s2 | result |
|----|-----|--------|
| "abcde" | "ace" | 3 |
| "abc" | "abc" | 3 |
| "abc" | "def" | 0 |

---

## 알고리즘 선택 분석

점화식:
```
dp[i][j] = s1[0..i-1]과 s2[0..j-1]의 LCS 길이

s1[i-1] == s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1
s1[i-1] != s2[j-1]: dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

시간복잡도: O(n×m), 공간복잡도: O(n×m) → 1D 배열로 O(m)으로 최적화 가능.
