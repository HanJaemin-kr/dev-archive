# 04. Recursion (재귀)

## 1. 재귀란?

**함수가 자기 자신을 호출하며 문제를 줄여가는 방식.**
"큰 문제 = 같은 형태의 작은 문제 + 한 단계 처리" 로 정의 가능한 모든 문제는 재귀로 풀 수 있다.

### 도식 — 호출 스택

```
   call f(3)
     ┌──────────┐
     │  f(3)    │   ← 가장 위가 현재 실행 중
     ├──────────┤
     │  f(2)    │
     ├──────────┤
     │  f(1)    │
     └──────────┘
       (return 0)

   재귀 = "시스템 스택을 자동으로 쓰는 반복".
   DFS / 백트래킹 / 분할 정복은 모두 재귀의 응용.
```

### 재귀의 3요소

```
   1. 종료 조건 (base case)  → if (n === 0) return ...
   2. 자기 호출    (recursive case) → return f(n - 1) ...
   3. 합치는 방법  (combine)  → return process(f(...))
```

## 2. 시간/공간 분석

| 형태 | 점화식 | 결과 | 예 |
|------|--------|------|-----|
| 선형 재귀 | T(n) = T(n-1) + O(1) | O(n) | 팩토리얼 |
| 이중 선형 | T(n) = 2T(n-1) + O(1) | O(2ⁿ) | 하노이, 순수 피보나치 |
| 분할 정복 | T(n) = 2T(n/2) + O(n) | O(n log n) | 병합 정렬 |
| 분할 정복 | T(n) = 2T(n/2) + O(1) | O(n) | 트리 순회 |
| 분할 정복 | T(n) = T(n/2) + O(1) | O(log n) | 이진 탐색, 빠른 거듭제곱 |

> **마스터 정리**: `T(n) = a·T(n/b) + f(n)` 의 점근적 복잡도를 판단하는 공식.

**공간** = 재귀 깊이 × 프레임 크기. JS 엔진의 스택 한계는 보통 10⁴~10⁵ 수준.

## 3. JS 구현 템플릿

### 기본 재귀

```js
function factorial(n) {
  if (n <= 1) return 1;          // 종료 조건
  return n * factorial(n - 1);   // 자기 호출
}
```

### 메모이제이션 (Top-down DP)

```js
function fib(n, memo = new Map()) {
  if (n < 2) return n;
  if (memo.has(n)) return memo.get(n);
  const v = fib(n - 1, memo) + fib(n - 2, memo);
  memo.set(n, v);
  return v;
}
```

### 분할 정복 (빠른 거듭제곱)

```js
function pow(x, n) {
  if (n === 0) return 1;
  if (n < 0) return 1 / pow(x, -n);
  const half = pow(x, Math.floor(n / 2));
  return (n & 1) ? half * half * x : half * half;
}
```

### 재귀 → 반복 변환

```js
// 깊이가 깊을 때 (n ≥ 10^4) 는 반복문으로 변환
function fibIter(n) {
  let [a, b] = [0, 1];
  for (let i = 0; i < n; i++) [a, b] = [b, a + b];
  return a;
}
```

## 4. 대표 패턴

### 패턴 A — 자기 호출 + 종료 조건

```
   factorial(n) = n * factorial(n - 1)
   factorial(0) = 1   ← 종료 조건

   "큰 문제를 한 단계 줄인 같은 형태의 문제"로 정의.
```

용도: 팩토리얼, 피보나치, 누적합 정의

### 패턴 B — 분할 정복 (Divide & Conquer)

```
   문제를 절반(또는 일부)으로 나누고, 각각 재귀로 풀고, 합친다.

       f(n) ──┬── f(n/2) ──┬── f(n/4) ─ ...
               │             └── f(n/4) ─ ...
               └── f(n/2) ──┬── f(n/4)
                            └── f(n/4)

   T(n) = a·T(n/b) + combine(n)
```

```
   하노이 탑 — 정확히 분할 정복:

   hanoi(n, A, C, B):
     hanoi(n-1, A, B, C)   ← n-1개를 보조 기둥으로
     move(A → C)            ← 가장 큰 원판
     hanoi(n-1, B, C, A)   ← n-1개를 목표 기둥으로

   이동 횟수: 2^n - 1
```

용도: 병합/퀵 정렬, 이진 탐색, 거듭제곱, 트리 순회

### 패턴 C — 메모이제이션 (Top-down DP의 입구)

```
   순수 재귀 fib(n) = O(2^n)  → fib(40) 도 느림.

           fib(5)
          /      \
       fib(4)    fib(3)         ← fib(3) 중복!
       /    \    /    \
     fib(3) fib(2) fib(2) fib(1)
     ...

   메모: 한 번 계산한 값은 저장 → 매 입력당 한 번씩만 계산 → O(n).
```

용도: 같은 부분 문제 반복 시 — DP 의 진입로

### 패턴 D — 백트래킹

```
   재귀 호출 시 상태를 push,
   리턴 직전에 pop (= 상태 복원).

   dfs(idx, state):
     if idx === n: 결과 처리; return
     for choice in candidates:
       state.push(choice)
       dfs(idx + 1, state)
       state.pop()        ← 복원이 핵심
```

자세한 내용은 `07_backtracking/README.md`.

용도: 모든 부분집합/순열/조합, N-Queens, 미로 경로

## 5. 자주 하는 실수

- **종료 조건 누락** → 무한 재귀 → `RangeError: Maximum call stack`.
- **JS 스택 한계 (~10⁴)** → n = 10⁵ 이상에서는 반복문 변환 또는 명시적 스택 사용.
- **메모이제이션 키 충돌** — `[i, j]` 처럼 다차원 키는 문자열화(`${i},${j}`) 또는 2D 배열 사용.
- **재귀 호출 결과를 안 받음** → `f(n-1)` 만 호출하고 리턴 처리 누락.
- **백트래킹에서 push 후 pop 누락** → 다음 분기로 상태 누출.
- **객체/배열을 인자로 넘기면 참조 공유** → 복사 필요 시 `[...arr]`, `{...obj}`.

## 7. 한 줄 요약

> **"문제를 작은 자기 자신으로 줄일 수 있다면 재귀."**
>
> 종료 조건 + 자기 호출 + 합치는 방법 — 이 3가지만 정의하면 끝.
> 같은 부분 문제가 반복되면 메모이제이션, 깊이 깊으면 반복문 변환.
