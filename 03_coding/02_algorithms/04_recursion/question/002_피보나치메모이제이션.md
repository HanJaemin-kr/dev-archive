## 문제 설명

n번째 피보나치 수를 반환하라. 결과가 크면 `1234567`로 나눈 나머지 반환.  
`f(0)=0, f(1)=1, f(n)=f(n-1)+f(n-2)`

## 제한사항

| 항목 | 값 |
|------|-----|
| n | 0 이상 10⁵ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| n | result |
|---|--------|
| 3 | 2 |
| 5 | 5 |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 순수 재귀 | O(2^n) | n=100도 불가 |
| 메모이제이션 (Top-down) | O(n) | ✅ |
| 반복문 (Bottom-up) | O(n) | 스택 오버플로 없음 |

n=10^5이면 재귀 스택 깊이가 10만 → **JS 스택 오버플로** 위험.  
→ 반복문(DP) 방식 권장.
