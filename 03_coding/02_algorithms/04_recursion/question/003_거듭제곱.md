## 문제 설명

`x`의 `n`제곱을 반환하라. 음수 지수도 처리.  
n의 범위가 크므로 O(log n)으로 풀어야 한다.

## 제한사항

| 항목 | 값 |
|------|-----|
| x | -100 이상 100 이하 소수 |
| n | -2³¹ 이상 2³¹-1 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| x | n | result |
|---|---|--------|
| 2.0 | 10 | 1024 |
| 2.1 | 3 | 9.261 |
| 2.0 | -2 | 0.25 |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 |
|------|-----------|
| 반복 곱셈 | O(n) — n이 10^9이면 불가 |
| 분할 정복 | O(log n) | ✅ |

```
pow(x, n):
  n=0 → 1
  n<0 → 1 / pow(x, -n)
  n이 짝수 → pow(x*x, n/2)
  n이 홀수 → x * pow(x*x, (n-1)/2)
```
