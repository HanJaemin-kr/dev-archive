## 문제 설명

원판 n개를 기둥 A에서 기둥 C로 옮기는 모든 이동 과정을 반환하라.  
규칙: 한 번에 한 개, 큰 원판 위에 작은 원판만 가능.

## 제한사항

| 항목 | 값 |
|------|-----|
| n | 1 이상 20 이하 |
| 제한 시간 | 1초 |

## 입출력 예

```
n=2
result: [[1,2],[1,3],[2,3]]  (from, to)
이동 횟수: 2^n - 1 = 3
```

---

## 알고리즘 선택 분석

재귀 구조:
```
hanoi(n, from, to, via):
  hanoi(n-1, from, via, to)  // n-1개를 via로
  move(from, to)              // 가장 큰 원판 이동
  hanoi(n-1, via, to, from)  // n-1개를 to로
```

시간복잡도: O(2^n) — 이동 횟수가 2^n - 1이므로 불가피.
