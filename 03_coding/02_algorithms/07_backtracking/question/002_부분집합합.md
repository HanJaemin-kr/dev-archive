## 문제 설명

정수 배열 `nums`와 목표값 `target`이 주어졌을 때,  
합이 `target`인 부분집합의 수를 반환하라. (중복 원소 있을 수 있음)

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 20 이하 |
| 값 범위 | -30 이상 30 이하 |
| target | -1000 이상 1000 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| nums | target | result |
|------|--------|--------|
| [1,2,3] | 3 | 2 |
| [0,0,0] | 0 | 8 |

---

## 알고리즘 선택 분석

DFS로 각 원소를 "포함/미포함" 두 가지로 분기.  
총 2^n가지 경우 → N=20이면 2^20 ≈ 10^6 → 가능.

가지치기: 현재 합이 이미 target을 초과하면 중단 (양수만 있을 때).
