## 문제 설명

`begin` 단어를 `target`으로 변환하는 최소 단계 수를 반환하라.  
- 한 번에 한 글자만 변경 가능
- 변경 후 단어는 `words` 목록에 있어야 함
- 변환 불가능하면 0 반환

## 제한사항

| 항목 | 값 |
|------|-----|
| 단어 길이 | 3 이상 10 이하 |
| words 크기 | 3 이상 50 이하 |
| 모든 단어 길이 동일 |
| 제한 시간 | 1초 |

## 입출력 예

| begin | target | words | result |
|-------|--------|-------|--------|
| "hit" | "cog" | ["hot","dot","dog","lot","log","cog"] | 4 |
| "hit" | "cog" | ["hot","dot","dog","lot","log"] | 0 |

---

## 알고리즘 선택 분석

그래프 탐색 문제.  
각 단어를 노드, 한 글자 차이인 단어끼리 간선 연결.

| 방법 | 결과 |
|------|------|
| BFS | 최단 단계 보장 ✅ |
| DFS + 백트래킹 | 모든 경로 탐색 후 최솟값 |

단어 수가 최대 50개로 작아서 DFS도 충분.
