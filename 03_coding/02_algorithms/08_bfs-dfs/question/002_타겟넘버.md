# 002. 타겟 넘버

- **유형**: DFS / BFS
- **출처**: Programmers Lv.2
- **날짜**: 2026-05-17
- **제출 날짜**: 2026-07-07
- **결과**: 통과

---

## 문제 설명

정수 배열 `numbers`의 각 원소에 `+` 또는 `-`를 붙여서 `target`을 만드는 경우의 수를 반환하라.

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 2 이상 20 이하 |
| 원소 | 1 이상 50 이하 |
| target | 1 이상 1000 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| numbers | target | result |
|---------|--------|--------|
| [1,1,1,1,1] | 3 | 5 |
| [4,1,2,1] | 4 | 2 |

---

## 알고리즘 선택 분석

각 원소마다 +/-를 선택 → 이진 트리 탐색.  
총 2^n가지, n=20 → 2^20 ≈ 10^6 → DFS로 충분.

```
DFS(idx, current):
  idx == n → current == target이면 count++
  DFS(idx+1, current + numbers[idx])
  DFS(idx+1, current - numbers[idx])
```

---

## 내 풀이

```js
function solution(numbers, target) {
  let count = 0;

  function dfs(index, sum) {
    if (index === numbers.length) {
      if (sum === target) count++;
      return;
    }
    dfs(index + 1, sum + numbers[index]); // + 노드
    dfs(index + 1, sum - numbers[index]); // - 노드
  }
  dfs(0, 0);

  return count;
}
```

### 핵심 구조

```
              dfs(0, 0)
             /         \
      dfs(1, +1)      dfs(1, -1)
       /      \         /      \
  dfs(2,+2) dfs(2,0) dfs(2,0) dfs(2,-2)
  ...
```

각 숫자마다 `+` / `-` 두 갈래로 분기 → 리프(index === n)에서 합계 확인.  
`n = 20` → 최대 2²⁰ ≈ 10⁶ 호출 → 시간 제한 내 충분.

## 복잡도

- 시간: O(2^n) — 각 원소마다 +/- 두 갈래
- 공간: O(n) — 재귀 호출 스택 깊이

## 막혔던 점 / 오답 노트

- `count`를 클로저로 관리 → 반환값 없이 내부에서 누적, 깔끔.
- `index === numbers.length` 조건이 기저(base case). 이 조건 없으면 무한 재귀.
- 별도 `visited` 불필요 — 배열 인덱스 순서가 방문 순서를 보장.
