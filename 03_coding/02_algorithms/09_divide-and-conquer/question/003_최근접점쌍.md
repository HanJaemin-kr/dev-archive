## 문제 설명

2D 평면의 점 목록이 주어졌을 때, 가장 가까운 두 점 사이의 거리를 반환하라.  
(거리의 제곱 반환 — 소수점 오차 방지)

## 제한사항

| 항목 | 값 |
|------|-----|
| 점 수 | 2 이상 10⁵ 이하 |
| 좌표 | -10⁸ 이상 10⁸ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| points | result |
|--------|--------|
| [[0,0],[3,4],[1,1]] | 2 |
| [[0,0],[1,0],[2,0]] | 1 |

---

## 알고리즘 선택 분석

| 방법 | 시간복잡도 | 비고 |
|------|-----------|------|
| 브루트포스 | O(n²) | n=10^5 → TLE |
| 분할 정복 | O(n log n) | ✅ |

### 분할 정복 아이디어

```
1. x 기준 정렬
2. 중앙 기준으로 좌/우 분할
3. 각 절반에서 최근접 거리 d 구함
4. 경계 d 이내 점들 중 더 가까운 쌍 확인 (스트립 탐색)
```

스트립에서는 y 기준 정렬 후 최대 7개만 비교하면 됨 → O(n).
