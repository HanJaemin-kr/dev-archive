## 알고리즘 선택 분석

```
mergeSort(arr, lo, hi):
  if lo >= hi: return
  mid = (lo + hi) / 2
  mergeSort(arr, lo, mid)
  mergeSort(arr, mid+1, hi)
  merge(arr, lo, mid, hi)
```

항상 O(n log n). 안정 정렬. 추가 메모리 O(n).

재귀 깊이: log2(10^5) ≈ 17 → 스택 오버플로 없음.
