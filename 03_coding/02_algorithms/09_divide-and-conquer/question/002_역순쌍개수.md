# 002. 역순 쌍의 개수 (Inversion Count)

- **유형**: 분할 정복 / 병합 정렬 응용
- **날짜**: 2026-05-17
- **소요 시간**: 분

## 문제 설명

배열에서 `i < j`이지만 `arr[i] > arr[j]`인 쌍의 수를 반환하라.  
(역순 쌍 = 정렬에서 위치가 뒤바뀐 쌍)

## 제한사항

| 항목 | 값 |
|------|-----|
| 배열 크기 | 1 이상 10⁵ 이하 |
| 값 범위 | 1 이상 10⁹ 이하 |
| 제한 시간 | 1초 |

## 입출력 예

| arr | result |
|-----|--------|
| [2,4,1,3,5] | 3 |
| [1,2,3,4,5] | 0 |
| [5,4,3,2,1] | 10 |

---

## 알고리즘 선택 분석

```
N = 10^5 → 브루트포스 O(n²) = 10^10 → TLE
```

병합 정렬 응용: 병합 단계에서 역순 쌍 카운팅.

```
왼쪽 배열과 오른쪽 배열을 병합할 때:
오른쪽의 j번째 원소가 왼쪽의 i번째보다 작으면
→ 왼쪽 i번째부터 끝까지 (mid - i + 1)개가 모두 역순 쌍
```

O(n log n)으로 해결.
