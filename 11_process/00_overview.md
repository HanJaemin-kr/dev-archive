# 공정 산업(Process Industry) 큰그림

> 원료를 **연속적인 물리·화학 변환**을 거쳐 제품으로 바꾸는 산업.
> 철강·석유화학·정유·반도체·시멘트·제지 등이 여기에 속한다.
> 이 폴더(`11_process/`)는 회사가 아니라 **공정**을 기준으로 정리한다.

---

## 핵심 개념

### 1. 공정 산업 = "장치 산업"

일반 제조업(조립업)이 부품을 **조립**해 제품을 만든다면, 공정 산업은 **원료의 성질 자체를 바꾼다.**

- 철광석(돌) → 쇳물 → 철판  (화학적 환원 + 물리적 성형)
- 원유(기름) → 나프타 → 플라스틱 원료  (분리 + 반응)

이 변환을 **거대한 설비(장치)** 안에서 24시간 돌리기 때문에 "장치 산업"이라 부른다.
설비값이 수천억~조 단위라, **설비를 멈추지 않고 오래 안정적으로 돌리는 것**이 곧 돈이다.
→ 그래서 예지보전(`09_pdm`)이 공정 산업에서 특히 중요하다. [[09_pdm]]

### 2. 공통 흐름: 원료 → 가공 → 제품

```
원료 투입 → 전처리 → 주(主)반응/변환 → 분리·정제 → 후처리 → 제품 → 부산물/폐열 회수
```

어떤 공정을 봐도 이 뼈대는 비슷하다. 새 공정을 공부할 때 "이 단계는 위 흐름 중 어디에 해당하나?"를 먼저 물으면 길을 잃지 않는다.

### 3. 연속공정 vs 배치공정

| 구분 | 연속공정(Continuous) | 배치공정(Batch) |
|------|----------------------|-----------------|
| 방식 | 원료가 쉬지 않고 흘러들어감 | 한 솥씩 넣고 → 반응 → 꺼냄 |
| 예시 | 고로(제선), 정유 증류탑 | 전로(제강) 1회 취련, 의약품 |
| 장점 | 대량·저비용·품질 균일 | 다품종·유연 |
| 멈추면 | 재가동에 며칠~수주 (치명적) | 상대적으로 유연 |

> 고로는 한 번 불을 붙이면 **수년~십수 년을 끄지 않고** 돌린다. 이 사실 하나가 철강 설비 관리의 성격을 전부 규정한다.

## 면접 예상 질문

- **Q. 공정 산업(장치 산업)의 특징은?**
  A. 원료의 성질을 물리·화학적으로 변환한다. 초기 설비 투자가 크고 고정비 비중이 높아, 설비 가동률과 안정 운전이 수익성을 좌우한다. 대부분 24시간 연속 운전.

- **Q. 연속공정과 배치공정의 차이와 각각의 예시는?**
  A. 연속공정은 원료가 끊김 없이 흐르며(고로, 정유 증류탑) 대량·균일 생산에 유리하나 정지 비용이 크다. 배치공정은 한 회분씩 처리하며(제강 전로, 의약품) 다품종 유연 생산에 유리하다.

- **Q. 왜 공정 산업에서 예지보전(설비 진단)이 중요한가?**
  A. 설비가 크고 비싸며 연속 운전하기 때문에, 갑작스러운 고장은 막대한 생산 손실과 안전사고로 이어진다. 진동·온도 등으로 고장을 미리 예측해 계획정비로 전환하면 비계획 정지를 줄일 수 있다.
